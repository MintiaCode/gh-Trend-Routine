# AstrBotDevs/AstrBot

▎ 複数IMプラットフォームを繋ぐAIエージェント基盤

ライセンス: AGPL-3.0
言語: Python
スター数: ⭐ 36700 (+62 今日)
トレンド順位: #10 (2026-07-19)

---
## 概要

AstrBotは、Telegram、Discord、QQ、WeChat、Slackなど15以上のメッセージングプラットフォームを横断して動作するオープンソースのAIエージェント・開発フレームワークです。プラットフォームごとに個別の連携を実装する必要をなくし、1つの基盤上で本番運用可能なAIチャットボットを構築できることを目指しています。Python 3.12以降で動作し、Docker、クラウドサービス、デスクトップアプリ、`uv`によるコマンドライン導入など複数のデプロイ手段を提供します。マルチモーダル対話、MCP連携、ナレッジベース、コード実行用のサンドボックス環境(Agent Sandbox)といった機能を備え、1,000以上のコミュニティプラグインをワンクリックで導入できるエコシステムも特徴です。個人のAIコンパニオンを作りたい開発者から、カスタマーサポート自動化やナレッジ管理を行いたい企業まで幅広い層をターゲットにしています。

---
## 主な機能・特徴

- マルチプラットフォーム対応 — QQ、WeChat、Telegram、Discord、Slackなど15以上のIMサービスに接続
- マルチモーダル・エージェント機能 — 画像などを含む対話とエージェント的タスク実行
- MCP統合 — Model Context Protocolによる外部ツール・データ連携
- 1,000以上のコミュニティプラグイン — ワンクリックインストール可能なエコシステム
- ナレッジベース・ペルソナ機能 — 用途に応じたカスタマイズが可能
- Agent Sandbox — コードを安全に隔離実行する環境
- Web UI/ChatUI — Web検索機能付きの管理・対話画面
- 自動コンテキスト圧縮・多言語対応 — 長期運用を意識した実用機能
