## 概要

ai-website-cloner-templateは、AIコーディングエージェント（主にClaude Code + Opus 4.7推奨）を使って任意のWebサイトをNext.jsコードベースに再現するためのテンプレートリポジトリです。`/clone-website <URL>` コマンド一発で、スクリーンショット取得・デザイントークン抽出・インタラクションスイープ→コンポーネント仕様書生成→並列ビルダーエージェントによるセクション構築→アセンブリ・QAという多段階パイプラインが自動で走ります。Claude Code・Codex・Cursor・GitHub Copilot等13以上のエージェントに対応し、Next.js 16 + shadcn/ui + Tailwind CSS v4の現代的スタックで出力します。プラットフォーム移行・ソースコード復元・学習目的に使える合法的なリバースエンジニアリングツールです。

---
## 主な機能・特徴

- `/clone-website`スキル — URL指定だけでWebサイト全体を自動複製する5段階パイプライン
- 並列ビルダーエージェント — git worktreeを活用したセクション並列構築で高速化
- 13+エージェント対応 — Claude Code・Codex・Cursor・Windsurf等すべての主要エージェント
- デザイントークン完全抽出 — getComputedStyle()値・インタラクション・レスポンシブを網羅
- Modern Stack出力 — Next.js 16 + React 19 + shadcn/ui + Tailwind v4 + TypeScript strict
- テンプレートリポジトリ — GitHubの「Use this template」で自分のリポジトリに即コピー
- AGENTS.md統合 — エージェントが自動でプロジェクト指示を読み取り動作
