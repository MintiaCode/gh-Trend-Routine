## 概要

「Linuxサーバーのセキュリティを確保する方法」は、Linuxサーバーを堅牢化するための包括的な実践ガイドです。CC-BY-SA 4.0ライセンスのもとで公開され、SSHの公開鍵認証・2要素認証の設定、UFWファイアウォール・Fail2ban・PSADによるネットワーク防御、sudoとsuの権限制限、PAMによる強力なパスワードポリシー、FireJailによるアプリケーションサンドボックス、CrowdSecによるコミュニティ主導の脅威インテリジェンスなど、実際の設定コマンドとともに各セキュリティ対策の意図と理由を解説しています。Linuxの基本知識を持つホームサーバー管理者を対象とし、コピー&ペーストで実行できるコマンドを提供しながら各設定の背景にある原則も理解できるよう設計されています。

---
## 主な機能・特徴

- SSH強化 — Ed25519鍵認証・sshd設定最適化・2要素認証・弱いDH鍵の除去
- ファイアウォール設定 — UFWによるデフォルト拒否ポリシーの実装
- 侵入検知 — PSAD・Fail2ban・CrowdSecによる多層防御
- 権限管理 — sudo/su制限とPAMによる強力なパスワードポリシー
- アプリケーション隔離 — FireJailによるサンドボックス化
- ファイル整合性監視 — ルートキット・マルウェアスキャンとログ監視
- 自動セキュリティ更新 — 脆弱性アラートと自動アップデート設定
