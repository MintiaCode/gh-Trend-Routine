# TencentCloud/TencentDB-Agent-Memory

▎ 4層構造で実現するAIエージェント長期記憶

ライセンス: 不明
言語: TypeScript
スター数: ⭐ 7562 (+351 今日)

---
## 概要

TencentDB Agent Memory は、外部APIに一切依存せずに完全ローカルで動作する、AIエージェント向けの長期記憶システムである。従来のフラットなベクトルストレージに依存する記憶方式では、会話が長くなるほどノイズが増え、重要な文脈が埋もれてしまうという課題があった。本プロジェクトはこの問題を、情報を4段階(L0:生ログ、L1:原子的事実、L2:シーンブロック、L3:ペルソナプロファイル)に階層化する「メモリレイヤリング」と、冗長なログをMermaid図で圧縮しつつnode_idで元情報への追跡性を保つ「シンボリックメモリ」という2つのアーキテクチャで解決する。OpenClawやHermesといったエージェントフレームワークと連携し、ローカルSQLiteからクラウドストレージまで柔軟に選択できる。長時間の対話を繰り返すAIエージェント開発者や、コンテキストウィンドウのトークン消費を抑えつつ精度を高めたいチームが主な対象ユーザーとなる。

---
## 主な機能・特徴

- メモリレイヤリング — 生ログから事実・シーン・ペルソナまで4段階で情報を構造化
- シンボリックメモリ — Mermaid図でログを圧縮しつつnode_idで元データに追跡可能
- ゼロ外部API依存 — 完全ローカル動作でプライバシーと低コストを両立
- OpenClaw/Hermes対応 — 主要エージェントフレームワークとのプラグイン連携
- トークン消費最大61.38%削減 — WideSearchベンチマークで実証
- タスク成功率51.52%向上 — 実運用に近いシナリオでの改善
- PersonaMem精度48%→76%向上 — ペルソナ理解の大幅な性能向上
- ローカルSQLite/クラウド両対応 — 用途に応じたストレージ選択が可能
