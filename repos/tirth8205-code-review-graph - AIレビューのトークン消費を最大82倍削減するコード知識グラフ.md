## 概要

code-review-graphは、AIコーディングツールがコードレビューや大規模リポジトリでの作業時にコードベース全体を無駄に読み込んでしまう問題を解決する、ローカルファーストのコード知識グラフツールです。Tree-sitterを用いて40以上の言語のソースコードを解析し、関数・クラス・import・呼び出し関係をSQLiteベースのグラフとして永続化します。ファイルが変更された際には「ブラストレディウス(影響範囲)分析」により、実際に影響を受ける呼び出し元・依存先・テストのみを特定し、AIアシスタントに必要最小限のコンテキストだけを提供します。MCP(Model Context Protocol)を通じて30種類のツールを公開し、Claude CodeやCursor、Copilot、Gemini CLIなど主要なAIコーディング環境と連携できます。対象ユーザーは、大規模モノレポでのAIレビューコストを削減したい開発チームや、AIエージェントのトークン消費を最適化したいプラットフォームエンジニアです。テレメトリなしのローカル完結設計も特徴です。

---
## 主な機能・特徴

- ブラストレディウス分析 — 変更ファイルから影響範囲(呼び出し元・依存先・テスト)を自動特定
- 40以上の言語対応 — Python, JS/TS, Go, Rust, Java, C/C++, C#ほか、Jupyter Notebookも対応
- MCP統合 — 30種類のツールをAIアシスタントに自動公開し必要な情報のみ提供
- インクリメンタル更新 — 変更ファイルのみ再解析し大規模プロジェクトでも2秒未満で完了
- Leidenクラスタリングによるコミュニティ検出 — 関連コードを自動グルーピング
- リスクスコアリング — PRレビュー時に影響関数・テスト不足箇所を可視化
- GitHub Actions連携 — プッシュごとに更新されるリスクスコア付きレビューコメント
- マルチリポジトリ対応 — デーモンによる複数リポジトリの同時監視
