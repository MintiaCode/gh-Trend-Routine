# NomaDamas/k-skill

▎ 韓国生活を自動化するAIスキル集

ライセンス: MIT
言語: JavaScript
スター数: ⭐ 6.7k (+103 今日)

## 概要

k-skillは、韓国国内のサービスをAIエージェントから直接操作できるようにする150以上のスキルを集めたモノレポである。SRT・KTX・高速バスなどの交通機関予約、不動産の実取引価格や公示地価の確認、競売公告の検索、行政・法務文書検索や事業者登録確認、税金滞納照会などの行政サービス、Coupang・Daiso・Naver・中古市場を横断した価格比較などのショッピング、コンサートチケットや映画館・スポーツ結果・ニュース集約といったエンタメ、天気・微細粉じん・EV充電スタンド・ゴミ収集スケジュールなどの生活インフラ情報まで、韓国生活に密着した幅広いドメインを自動化する。Claude Code・Codexなど主要なコーディングエージェントに対応しており、`npx skills add NomaDamas/k-skill --all -g`で一括インストールするか、必要なスキルだけを個別導入できる。認証情報が必要なスキルと不要なスキルが明確に区分されており、独自のAPIレイヤーを持たずプロキシサーバーへの直接リクエストで完結する設計思想が特徴である。韓国語話者・韓国在住者向けにAIエージェントを実用化したい開発者が主な対象ユーザーである。

---
## 主な機能・特徴

- 150以上の韓国特化スキル — 交通・不動産・行政・ショッピング・生活情報を網羅
- 交通機関予約 — SRT/KTX/高速バスの予約や運行情報取得に対応
- 行政・法務サービス — 事業者登録確認、税金滞納照会、公的データベース検索
- ショッピング価格比較 — Coupang/Daiso/Naver/中古市場を横断して比較
- Claude Code/Codex対応 — 主要コーディングエージェントにワンコマンドで導入可能
- 認証モデルの明確化 — ログイン要否・API鍵要否をスキルごとに区分
- プロキシ直結設計 — 追加のクライアントAPIレイヤーなしでシンプルに動作
- 生活インフラ情報 — 天気・微細粉じん・EV充電・ゴミ収集スケジュールを取得

## トレンド入り理由の推測

k-skillは本日103スターという大きな伸びを見せており、Claude CodeやCodexなど昨今急速に普及しているAIコーディングエージェント向けの「スキル」形式を採用している点が大きい。AnthropicのClaude Skillsなど、エージェントに特定タスクを教えるスキル・プラグインの仕組みが2026年に入り急速に一般化する中、特定の言語圏・生活圏に特化した実用的なスキル集は、汎用ツールでは対応しきれないニッチな需要を満たすものとして注目されやすい。

特に韓国では交通予約や行政手続きなど独自のオンラインサービスが多く、英語圏向けの汎用AIエージェントでは対応が難しい領域を150以上のスキルでカバーしている点が、韓国語話者コミュニティでの急速な拡散につながったと考えられる。「エージェントを韓国人に」というキャッチコピー通り、ローカライズされたAIエージェント活用への関心の高まりが、本日のトレンド入りの主因と推測される。
