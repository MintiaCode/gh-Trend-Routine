## 概要

shanraisshan/claude-code-best-practiceは、Claude Codeを活用したAIエージェント開発のベストプラクティスを体系的にまとめた包括的ガイドリポジトリである。「バイブコーディング」から「エージェンティックエンジニアリング」への進化を掲げ、Claude Codeのサブエージェント、コマンド、スキル、ワークフロー、フック、MCPサーバー、プラグイン、設定といった主要機能すべてについて、ベストプラクティスと実装例の両方を提供している。Anthropic社のBoris Chernyの推奨も受けており、初心者から上級者まで、Claude Codeを最大限に活用したい開発者を対象としている。各機能ごとにベストプラクティス文書と実装サンプルが対になって整理されており、すぐに自分のプロジェクトに適用できる実践的な構成が特徴である。コンテキストエンジニアリングやオーケストレーションワークフローなど、最新のAIエージェント開発手法もカバーしている。

---
## 主な機能・特徴

- サブエージェント設計 — Claude Codeのサブエージェント機能のベストプラクティスと実装パターンを詳細に解説
- コマンド体系 — スラッシュコマンドの設計・実装方法を体系的に整理し、再利用可能なワークフロー構築を支援
- スキル管理 — AIエージェントスキルの作成・管理・モノレポ対応まで包括的にカバー
- オーケストレーションワークフロー — 複数エージェントを協調させる複雑なワークフローの設計手法を提供
- フック機能 — Claude Codeのフック機能による自動化処理の設定ガイドと実装例
- MCPサーバー統合 — Model Context Protocolサーバーの設定と活用ベストプラクティス
- プラグインエコシステム — プラグインの作成・配布・マーケットプレイス活用方法を解説
- 設定最適化 — パーミッション、モデル設定、出力スタイル、サンドボックスなどの最適な構成例
