## 概要

claude-code-templatesは、Anthropic Claude Codeの設定・エージェント・コマンド・MCPなどを管理するCLIツールとテンプレートコレクションです。100以上のエージェント・カスタムコマンド・設定・フック・外部連携（MCPs）・プロジェクトテンプレートを即座にインストールできるインタラクティブなインターフェースを提供します。npx一行コマンドで開発チーム全体の構成を導入したり、GitHub・PostgreSQL・AWS・Stripeなどの外部サービスとの連携も設定できます。さらにClaude Codeのセッション分析・会話モニタリング・ヘルスチェックなどの開発支援ツールも同梱されており、Claude Code利用者の生産性を包括的に高めます。

---
## 主な機能・特徴

- 100以上のテンプレート — エージェント・コマンド・MCP・設定・フック・スキルを網羅
- npxワンライン導入 — `npx claude-code-templates@latest`で対話的に選択・インストール
- Claude Code Analytics — AIセッションをリアルタイムで監視しパフォーマンスメトリクスを可視化
- 会話モニター — Cloudflareトンネル経由でモバイルからもClaude応答を確認可能
- 外部連携MCPs — GitHub・PostgreSQL・Stripe・AWSなど主要サービスとの統合設定
- ヘルスチェック — Claude Codeインストール環境の包括的な診断ツール
- コミュニティ駆動 — 複数オープンソースプロジェクトからスキルを集約・クレジット付与
