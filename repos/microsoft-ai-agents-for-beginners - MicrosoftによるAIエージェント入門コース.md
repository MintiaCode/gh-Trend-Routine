## 概要

AI Agents for Beginnersは、Microsoftが提供するAIエージェント構築のための無料オンラインコースです。15以上のレッスンを通じてAIエージェントの基礎から本番デプロイまでを体系的に学べます。Microsoft Agent Framework（MAF）とAzure AI Foundry Agent Service V2をメインツールとして使用しており、OpenAI互換プロバイダーにも対応しています。各レッスンには日本語を含む偶以上の言語に翻訳された文書・Pythonコードサンプル・解説動画・補足リソースが付属します。62,400スターと 21,000フォークという規模は Microsoftの教育コンテンツの中でもトップクラスの人気を誤り、GitHubで学べるAIエージェント入門として最も包括的なリソースの一つです。

---
## 主な機能・特徴

- 15+レッスン — 入門から本番デプロイまでの体系的カリキュラム
- 50+言語翻訳 — GitHub Actionsによる自動翻訳で日本語含む多言語対応
- Microsoft MAF対応 — AutoGen・Semantic KernelなどMS製フレームワークをカバー
- Azure AI Foundry V2 — クラウドベースのエージェント開発環境と連携
- 動画付きレッスン — 各章に解説動画を完備しマルチモーダルな学習体験
- Discordコミュニティ — 学習者同士の質問・議論の専用チャンネルを提供
