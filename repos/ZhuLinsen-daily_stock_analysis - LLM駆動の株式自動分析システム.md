## 概要

daily_stock_analysisは、LLM（大規模言語モデル）を活用したA株・香港株・米国株の自動分析システムです。毎日自動で「決策仪表盘（意思決定ダッシュボード）」を生成し、企業WeChat・飛書・Telegram・Discord・Slack・メールなど多彩な通知チャンネルへプッシュします。技術面分析・リアルタイム株価・ニュース感情分析・資金フロー・ファンダメンタルズを多角的に集約し、一言の核心結論とスコア・売買ポイント・リスク警報・操作チェックリストを出力します。GitHub Actionsを使えばゼロコスト・ゼロサーバーで定期実行でき、5分でデプロイ可能です。Gemini・OpenAI・DeepSeek・Claude・通義千問・Ollamaなど幅広いLLMプロバイダーをサポートしています。

---
## 主な機能・特徴

- AI意思決定ダッシュボード — 核心結論・評価スコア・売買ポイント・リスク警報をワンストップ生成
- グローバル市場対応 — A株・香港株・米株・ETFを横断的に分析
- 多次元分析 — 技術面・リアルタイム株価・チップ分布・ニュース感情・資金フロー・ファンダメンタルズを統合
- Agent問株機能 — 均線ゴールデンクロス・缠論・波浪など11種の内蔵戦略で多段階Q&A対話
- 多チャンネル通知 — WeChat企業版・飛書・Telegram・Discord・Slack・メールに対応
- ゼロコスト自動化 — GitHub Actionsで定期実行、サーバー不要
- AIバックテスト — 過去の分析結果を事後検証し方向精度・模擬収益を評価
