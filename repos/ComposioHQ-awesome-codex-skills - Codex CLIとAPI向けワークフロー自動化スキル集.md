## 概要

OpenAI Codex CLIおよびAPIのワークフロー自動化に特化したモジュール型スキル（指示バンドル）のキュレーションリストです。Codexスキルとは「Codexがタスクをどのように実行するか」を定義したモジュール型の指示バンドルで、コードレビュー・メール送信・GitHub Issue作成・Slack投稿・スプレッドシート操作など1,000以上のアプリへのアクションを自動化できます。開発・コードツール、生産性・コラボレーション、コミュニケーション・ライティング、データ・分析、メタ・ユーティリティの5カテゴリに整理されており、`SKILL.md`ファイルにYAMLフロントマターでスキルを定義するシンプルな構造です。ComposioHQが開発し、GPT-5・GPT-5.1 Codexをターゲットとしたエコシステムの中心的なリソースです。

---
## 主な機能・特徴

- 5カテゴリのスキル — 開発・生産性・コミュニケーション・データ・ユーティリティ
- 1,000以上のアプリ対応 — Composio経由でSlack・Notion・GitHubなどと統合
- モジュール型構造 — SKILL.mdのYAMLフロントマターでスキルを簡単に定義・拡張
- スキルインストーラ — GitHubから直接スキルをフェッチして自動配置
- 開発ツール系スキル — コードレビュー・マイグレーション・CI/CD自動化
- コミュニケーション系スキル — メール下書き・変更ログ生成・コンテンツリサーチ
- コントリビューション歓迎 — コミュニティによるスキルの追加・改善を推奨
