# czlonkowski/n8n-mcp

▎ n8nワークフロー自動構築MCPサーバー

スター数: ⭐ 19421 (+264 今日)

---
## 概要

n8n-MCPは、Claude DesktopやClaude Code・Cursor・WindsurfなどのAIアシスタントに対し、n8nのワークフロー自動化ノード情報を包括的に提供するModel Context Protocolサーバーです。1,650のn8nノード（コア820個＋コミュニティ830個）のドキュメント・プロパティ・操作方法をAIが理解できる形式で提供し、AIがn8nワークフローを自律的に設計・構築できるようにします。2,352件のワークフローテンプレートライブラリや156件の実際の設定例を持ち、Claude等のAIが実践的なオートメーションワークフローを生成する際の知識基盤として機能します。クラウド版（ダッシュボード）とセルフホスト版の両方に対応しています。

---
## 主な機能・特徴

- 1,650ノードの網羅的なドキュメント提供 — コア820個＋コミュニティ830個のn8nノードをAIが参照可能
- ワークフローテンプレートライブラリ — 2,352件のテンプレートとAIメタデータ（99.96%カバー率）を搭載
- 265種のAIツールバリアント — AI機能を持つノードを特定・完全ドキュメント化して提供
- マルチIDE対応 — Claude Code・Cursor・Windsurf・VS Code・Codexなどと即座に接続可能
- クラウド版ダッシュボード — インストール不要、1日100ツールコール無料で即座に試用可能
- 5,418テスト全合格のCI/CD — 高い信頼性とn8n 2.18.4への追従を保証
- セルフホスト対応 — npx・Docker・Railway・ローカルインストールの複数デプロイ方法
- スキル拡張システム — n8n-skillsリポジトリと連携し、本番品質ワークフロー生成を強化
