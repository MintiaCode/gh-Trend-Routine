## 概要

browserbase/skillsは、Claude Agent SDKにWebブラウザ自動操作機能を追加するスキルプラグインです。Browserbaseサービスを活用し、アンチボットステルス機能・CAPTCHAソルバー・住宅IPプロキシを備えた高度なリモートブラウザ自動化をCLIから実現します。Claude Codeのマーケットプレイスから簡単にインストールでき、ニュース記事の要約・QAテスト・認証済みセッション管理・サーバーレスブラウザ自動化デプロイなど幅広いユースケースに対応しています。さらにブラウザトレースのキャプチャ・デバッグ機能・使用統計モニタリング・クッキー同期・静的コンテンツ取得・Web検索など計11種類のスキルを提供し、StagehandやClaude Code Skillsとの統合も可能です。

- セッション管理 — クッキー同期による認証済みブラウザセッションの管理
- 多用途対応 — ニュース要約・QAテスト・スクレイピング・Web検索など11種類のスキル
