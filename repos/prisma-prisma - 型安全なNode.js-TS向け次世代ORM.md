## 概要

Prismaは、Node.jsおよびTypeScript向けの次世代ORM(Object-Relational Mapping)ツールであり、PostgreSQL、MySQL、MariaDB、SQL Server、SQLite、MongoDB、CockroachDBなど幅広いデータベースに対応する。従来のORMが抱えていた「型の不整合によるランタイムエラー」や「複雑なクエリ記述の煩雑さ」といった課題を、スキーマファイルによる宣言的なデータモデリングと、そこから自動生成される型安全なクエリビルダーによって解決する。主要コンポーネントはPrisma Client(型安全なクエリビルダー)、Prisma Migrate(宣言的マイグレーション管理)、Prisma Studio(GUIによるデータ閲覧・編集)の3つで構成される。開発者はスキーマを定義するだけでfindMany()やcreate()などの直感的なメソッドでデータベース操作ができ、コンパイル時にエラーを検出できる。バックエンド開発者やフルスタックTypeScript開発者を主なターゲットとし、開発生産性と型安全性を両立したいチームに広く採用されている。

---
## 主な機能・特徴

- Prisma Client — 自動生成される型安全なクエリビルダー
- Prisma Migrate — 宣言的なスキーマ管理とマイグレーション
- Prisma Studio — データ閲覧・編集用GUIツール
- 7種類のデータベースに対応 — PostgreSQL/MySQL/MariaDB/SQL Server/SQLite/MongoDB/CockroachDB
- コンパイル時型チェック — TypeScriptとの高い親和性
- 直感的なクエリAPI — filtering・relations・nested操作を簡潔に記述
- prisma.config.tsによる柔軟な接続設定
- 活発なコミュニティ — DiscordとGitHubで継続的にサポート
