## 概要

awesome-claude-codeは、Anthropicのコーディングエージェント「Claude Code」向けのスキル・プラグイン・MCPサーバー・ドキュメント・学習リソースなどを分野別に整理した、コミュニティ主導のキュレーションリストです。単なるリンク集ではなく、"Awesome"形式の品質基準に沿って厳選されており、公式リソース(Anthropic発)から個人開発のツールまで幅広く網羅しています。現行版は「これまで掲載されていなかった良質なリソースを優先的に紹介する」という方針で再構成された最新イテレーションであり、過去の掲載内容は README_ALTERNATIVES ディレクトリにアーカイブとして保持されています。カテゴリはドキュメント・学習、研究、インフラ、リモート制御、デザイン、セキュリティ、マルチエージェント編成、スキル、メモリ、コスト監視、Observabilityなど多岐にわたり、Claude Codeのエコシステムを俯瞰したい開発者にとっての入口となることを目指しています。

---
## 主な機能・特徴

- カテゴリ別リソース集 — スキル・プラグイン・MCP・ドキュメントを分野別に整理
- Claude Code Ticker — 注目リポジトリをSVGバナーで可視化
- Recently Added セクション — 新着リソースを随時掲載
- コミュニティ主導の再選定 — 過去に未掲載だった良質リソースを優先
- README_ALTERNATIVES — 旧版の掲載内容もアーカイブとして保持
- Awesome形式準拠 — awesome.re基準に沿った品質管理
- Anthropic公式リソースも網羅 — 公式ブログ・ガイド・GitHub Actionを収録

## トレンド入り理由の推測

本日のトレンドにはmarketingskillsやtaste-skill、cavemanなどClaude Code向けスキル・プラグインリポジトリが数多く並んでおり、Agent Skills仕様の普及とともにエコシステム全体が急拡大していることが伺えます。awesome-claude-codeはこうした個別ツールの「ハブ」として機能するため、周辺エコシステムが盛り上がるほど発見経路として参照される機会が増え、間接的にスター増加につながっていると考えられます。

また本リストは直近で「未掲載の良質リソースを優先的に紹介する」形へと大幅リニューアルされたばかりであり、この再構成自体が既存フォロワーやSNSでの再共有を呼び、新規流入を後押ししている可能性があります。584件を超えるIssueが示すように、コントリビューションが活発なプロジェクトである点も継続的な注目を集める要因です。
