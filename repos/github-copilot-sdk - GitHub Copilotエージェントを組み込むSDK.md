# github/copilot-sdk

## 概要

GitHub Copilot SDKは、GitHub Copilotのエージェント機能をアプリケーションやサービスに組み込むためのマルチプラットフォームSDKです。Python・TypeScript・Go・.NET（C#）・Java・Rustの6言語に対応しており、Copilot CLIが提供する同じ実行エンジン（プランニング・ツール呼び出し・ファイル編集など）をプログラムから呼び出せます。JSON-RPCでSDKクライアントがCopilot CLIサーバーと通信する設計で、開発者は独自のオーケストレーション層を構築することなく、エージェントの動作定義だけに集中できます。npm・PyPI・NuGet・Go・Cargo・Maven Centralの各パッケージマネージャーから簡単にインストール可能で、2026年6月2日の最新リリースにより67以上のリリースが提供されています。

---
## 主な機能・特徴

- 6言語対応SDK — Python・TypeScript・Go・.NET・Java・Rustすべてに同等のAPI提供
- エージェントランタイム統合 — Copilot CLIと同一の本番実証済みエンジンを利用可能
- ゼロオーケストレーション — プランニング・ツール呼び出し・ファイル編集はSDKが自動処理
- JSON-RPC通信 — SDKとCopilot CLIサーバー間のクリーンなプロトコル設計
- 全パッケージマネージャー対応 — npm・PyPI・NuGet・Go・Cargo・Mavenから即インストール
- 豊富なサンプル — awesome-copilot・Cookbookによるプラクティカルなドキュメント
- 継続的リリース — 67以上のリリース実績、活発なメンテナンス

## トレンド入り理由の推測

GitHubがCopilot SDKを正式公開したことで、企業や開発者が自社アプリにCopilotのエージェント機能を直接組み込めるエコシステムが確立されたことが、今日のトレンド入りの背景にあります。2026年6月2日のJava SDK最新リリースにより、エンタープライズ向けのJava/Spring Boot対応が強化された点も注目を集めています。

AIエージェントの「組み込み」需要が急増する中、GitHubというメジャーブランドが公式SDKを6言語同時に提供したことは業界として画期的です。Copilot CLIが既に広く普及していることで、「使い慣れたCopilotの能力を自社製品に内蔵したい」というニーズに直接応える製品として、特に企業のエンジニアリングチームから強い関心を集めています。

また、オープンソース（MIT）として公開されている点が透明性への信頼感を高め、競合のOpenAI・Anthropic系SDKとの差別化として、GitHubのエコシステム（Issues、PR、Actionsとの統合）を活用できる点がエンタープライズユーザーに訴求していると推測されます。
