# microsoft/pg_durable

▎ PostgreSQL内蔵の耐障害性ワークフロー実行基盤

ライセンス: PostgreSQL License
言語: Rust
スター数: ⭐ 1400 (+314 今日)

---
## 概要

pg_durableは、PostgreSQLのエクステンションとして動作する耐障害性ワークフロー実行フレームワークです。Temporal、Conductor、AWS Step Functionsのような外部オーケストレーションサービスを使わずに、データベース内部で長時間実行・耐障害性を持つワークフローを定義・実行できます。クロンジョブ・ワーカー・キュー・ステータステーブルをつなぎ合わせることなく、SQLで直接ワークフローを記述し、各ステップを自動チェックポイント化します。クラッシュや再起動が発生しても、最後のチェックポイントから自動的に再開されます。ベクトルエンベディングパイプライン、データ取り込み・変換、スケジュールメンテナンス、外部APIワークフローなどの用途を想定しており、`~>`や`|=>`などのSQL演算子でワークフローを合成的に記述できます。Rust + pgrxで実装されており、プレビュー段階ではありますがMicrosoftによって開発されています。

---
## 主な機能・特徴

- SQLネイティブ記述 — `~>`や`|=>`演算子でワークフローをSQLで直接定義
- 外部インフラ不要 — PostgreSQLエクステンションのみで動作、追加サービス不要
- 自動チェックポイント — 各ステップを自動保存し、クラッシュ後も再開可能
- AIパイプライン対応 — ベクトルエンベディング・AIワークフローのユースケースに特化
- 並列実行サポート — ファンアウト・集計クエリの並列実行プリミティブを内蔵
- スケジュール機能 — スケジュール・条件・並列実行のファーストクラスプリミティブ
- 耐障害性保証 — PostgreSQLのACIDとともに状態を永続化し確実な実行を保証
