# alireza0/s-ui

▎ Sing-Box向け高機能プロキシ管理ウェブパネル

ライセンス: GPL-3.0
言語: Go
スター数: ⭐ 8,900 (+25 今日)
トレンド順位: #18 (2026-05-21)

---
## 概要

s-uiは、SagerNet/Sing-Boxをバックエンドとした高機能ウェブ管理パネルです。VLESS・VMess・Trojan・Shadowsocks・Hysteria・TUIC・ShadowTLSなど現代的なプロキシプロトコルを一元管理できる直感的なダッシュボードを提供します。検閲回避や企業内トラフィック管理、プライバシー保護のためのセルフホストVPN/プロキシ環境を構築する際のフロントエンドとして広く活用されています。

クライアント別トラフィック制限と有効期限管理、リアルタイムのオンラインクライアント監視・システム統計・トラフィックグラフ、サブスクリプション形式（リンク・JSON・Clash）での設定配布、HTTPS対応とSSL証明書管理など、プロバイダー運用に必要な機能を網羅しています。Linux（amd64/arm64/armv7他）・Windows・macOS（実験的）に対応し、Dockerやbashスクリプトで簡単にデプロイできます。ダークモード・ライトモードと英語・ファルシ語・ベトナム語・中国語・ロシア語のマルチ言語対応も特徴です。

---
## 主な機能・特徴

- マルチプロトコル対応 — VLESS/VMess/Trojan/Shadowsocks/Hysteria2/TUIC/ShadowTLSを一元管理
- クライアント管理 — トラフィック上限・有効期限・接続数制限の個別設定
- リアルタイムモニタリング — オンライン人数・帯域使用量・システム負荷をダッシュボード表示
- サブスクリプション配布 — リンク形式・JSON・Clashフォーマットでクライアントへ設定配信
- HTTPS/SSL対応 — 証明書管理による安全な管理画面アクセス
- マルチ言語UI — 英語・ファルシ語・ベトナム語・中国語（簡繁）・ロシア語に対応
- 柔軟なデプロイ — Docker Compose・bashスクリプト・Windowsインストーラーで簡単導入

## トレンド入り理由の推測

s-uiがトレンド入りしている背景には、インターネット検閲が厳しい地域での需要の継続的な高まりがあります。Sing-BoxはV2Ray・Xrayの後継として機能が豊富な一方、CLIベースの設定が複雑なため、WebUIを提供するs-uiへの需要が絶えません。v1.4.2（May 19, 2026リリース）の直後のトレンドインであり、新バージョンのリリースノートがコミュニティで共有されたことが本日のスター流入を促したと見られます。

Hysteria2やTUICなど最新の高速プロトコルへの迅速な対応と、Sing-Boxのエコシステムではほぼデファクトスタンダードのパネルとしての地位を確立していることが、毎リリース後にトレンド入りする持続的な人気の源泉です。また、既存の3x-ui（X-UI系）からの移行を検討するユーザーが、最新プロトコル対応を軸にs-uiを選択するケースが増えており、SEまたはネットワーク管理者向けコミュニティでの口コミ普及が本日の流入に貢献しているとみられます。
