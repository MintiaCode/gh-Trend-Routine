# JuliusBrussee/caveman

▎ Claude Code用トークン削減スキル

ライセンス: MIT
言語: JavaScript
スター数: ⭐ 80600 (+866 今日)
トレンド順位: #2 (2026-07-02)

---
## 概要

Caveman は、Claude Code をはじめとする30以上のコーディングエージェントの出力を「原始人のような片言」に圧縮することで、トークン消費量を平均65%削減するスキルである。「why use many token when few token do trick」というキャッチコピーが象徴する通り、AIの思考能力自体は落とさず、冗長な言い回しや前置き、丁寧な説明文だけを削ぎ落とし、要点だけを断片的な文で伝えるスタイルに変換する。ユーザーの入力言語（日本語、ポルトガル語、スペイン語など）は保持しつつ、応答スタイルのみを圧縮する点が特徴で、コードやコマンド、エラーメッセージ自体は改変しない。lite・full・ultra・wenyan（漢文調）という4段階の圧縮レベルを備え、`/caveman-commit` や `/caveman-review` など関連コマンドも提供する。API利用コストの高騰とコンテキスト消費に悩む開発者を主な対象とし、体感速度と可読性の向上を主目的としている。

---
## 主な機能・特徴

- 出力圧縮スキル — Claude Code等の応答トークンを平均65%削減
- 4段階の圧縮レベル — lite / full / ultra / wenyan(漢文調)
- 多言語対応 — ユーザーの入力言語は保持し文体のみ圧縮
- コミット生成 — `/caveman-commit` で50文字以内のConventional Commit生成
- レビュー支援 — `/caveman-review` で一行PRフィードバック
- 統計表示 — `/caveman-stats` でトークン削減量とコスト削減額を可視化
- ワンライン導入 — 30以上のエージェントに単一コマンドでインストール可能
- 関連ツール群 — cavemem、cavekit、cavegemma等の兄弟プロジェクトが存在

## トレンド入り理由の推測

「why use many token when few token do trick」というミーム性の高いキャッチコピーと、原始人口調という強烈にキャッチーなコンセプトがSNSやコミュニティで急速に拡散したことが最大の要因と考えられる。実測ベンチマークで「あるReactの再レンダリングバグの説明が1,180トークンから159トークンへ、87%削減された」という具体的で分かりやすい数値を提示している点も、開発者の関心を引きやすい。

今日だけで866スターを獲得しており、AIコーディングエージェントの利用コスト・コンテキスト消費が2026年の開発者コミュニティで大きな関心事になっている流れとも合致する。Claude Code、Codex、Cursor、Gemini、Copilotなど主要エージェント30種以上に対応する汎用性の高さと、v1.9.0という活発なリリースサイクルも、実用ツールとしての信頼性を後押しし、トレンド入りにつながったと推測される。
