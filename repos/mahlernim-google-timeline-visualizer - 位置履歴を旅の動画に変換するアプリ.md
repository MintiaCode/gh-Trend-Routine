# mahlernim/google-timeline-visualizer

## 概要

google-timeline-visualizer は、Google の位置情報履歴(Timeline)のエクスポートデータを読み込み、一年の移動の軌跡を地図上のアニメーション動画として書き出すツールである。Android ネイティブアプリと iOS 向けの Web アプリの二形態で提供され、出力は MP4 として端末内に保存される。

Google Timeline は膨大な移動記録を蓄積しているが、公式の閲覧画面では日単位の断片としてしか眺められず、「一年をどう動いたか」という全体像を掴むことができない。エクスポートした JSON は開いたところで人間が読めるものではない。このギャップを埋めるのが本ツールで、退屈な座標列を、地図がカメラを追いながら軌跡を描いていく視覚的なストーリーへ変換する。Spotify Wrapped のような「年間まとめ」体験を、自分の移動履歴に対して自分の手元だけで作れる点が本質的な価値である。

処理面では単純な点の再生に留まらず、GPS 外れ値のフィルタリング(既定は保守的、無効化も可能)、長距離フライトや疎な区間に対する大圏補間、カメラの揺れを抑える局所的な平滑化、経路の形状を保ったまま長時間の移動を圧縮する処理などが組み込まれている。動画は 10〜300 秒の任意の長さ、正方形 480p/720p/1080p に加え縦長・横長のプリセットを選べ、カメラは固定ズームと移動追従のどちらかを指定できる。レンダリング前のプレビュー、サムネイルと日付・尺を自動記録するライブラリ、シーク対応のフルスクリーンプレイヤーも備える。プライバシー方針は明確で、Google サインイン・位置情報権限・アカウント権限・アナリティクス・広範なストレージ権限のいずれも使用せず、Timeline ファイルは端末外へ出ない。外部通信は CARTO/OpenStreetMap の地図タイル取得のみで、それも読み込み前に事前告知される。Android は 8.0 以上で APK 配布、iPhone は Safari 16.4 以上で Web アプリとして動作し、コマンドラインを好むユーザー向けに FFmpeg を使う旧来の Python 版も残されている。

---
## 主な機能・特徴

- Timeline から MP4 生成 — エクスポートデータを読み込み移動軌跡のアニメーション動画を出力
- 期間指定 — 任意の日付範囲または月単位を選んで可視化
- カメラ挙動の選択 — 固定ズームと移動追従の 2 モードを切り替え
- GPS 外れ値除去 — 保守的な既定フィルタで飛び値を除去、必要に応じて無効化可能
- 大圏補間と平滑化 — 長距離フライトや疎な区間を自然に繋ぎ、カメラの揺れを抑制
- 出力形式の多様性 — 10〜300 秒、正方形 480p/720p/1080p と縦長・横長プリセット
- 端末内完結のプライバシー設計 — サインイン・位置情報権限・アナリティクス一切なし
- Android / iOS 両対応 — APK 配布と Safari 向け Web アプリ、加えて Python 製 CLI 版も併存

## トレンド入り理由の推測

総スター 1,400 のうち 575 が今日という、極端なスパイク型の伸びである。全体の 4 割が一日で積み上がっており、公開直後、あるいは大手コミュニティで紹介された直後の典型的な形をしている。個人の移動履歴を美しい動画にするというアイデアは、スクリーンショットや作例動画そのものが宣伝素材として機能するため、SNS 上で極めて拡散しやすい種類のプロジェクトである。

需要面では、プライバシー意識と「自分のデータを自分で使いたい」という欲求の交差点にある。Google Timeline は近年、履歴の保存先が端末側へ移り、ユーザーが自分でエクスポートを管理する形へと変化してきた。その結果「手元に JSON はあるが何もできない」という人が大量に生まれており、本ツールはその滞留したデータに出口を与えている。しかも Google サインインも位置情報権限も一切要求しないという設計は、位置履歴という最も機微なデータを扱う上で説得力があり、警戒心の強いユーザーにも届いた。

技術的な作り込みも軽視できない。この手の可視化ツールは往々にして「点を順番に打つだけ」で終わり、飛行機移動で地図が瞬間移動したりカメラがガタつく残念な出力になりがちである。大圏補間、外れ値除去、カメラ平滑化、経路形状を保った時間圧縮といった処理が最初から入っていることで、出来上がる動画が人に見せられる品質になっている。共有したくなる出力が出る、という一点が、この種のプロジェクトの拡散速度を決定づけたと考えられる。
