# anthropics/cwc-workshops

ライセンス: Apache-2.0
言語: TypeScript
スター数: ⭐ 1600 (+37 今日)

---
## 概要

本リポジトリは、Anthropicが開催したイベント「Code with Claude」のワークショップで使用された教材一式を公開したものです。Claudeやエージェント技術を実際の開発現場でどう活用するかを、モデル選定・マルチエージェント構成・エージェントの記憶保持・評価駆動開発・本番運用まで、9つの独立したモジュールに分けて体系的に学べる構成になっています。対象読者は、Claude Code や Anthropic API、Claude Agent SDK を使ってエージェント型アプリケーションを構築したいエンジニアやプロダクト開発者です。各ワークショップはディレクトリ単位で完結しており、モデル選択の基礎から、SECファイルやM&A分析を扱う調査エージェントのような高度な実務シナリオまで、段階的に難易度が上がる設計です。なお本リポジトリ自体は「メンテナンスなし・コントリビューション非受付」のアーカイブ的な位置づけで、あくまで学習素材の配布が目的です。

---
## 主な機能・特徴

- 9つの独立ワークショップ — モデル選定からマルチエージェント設計、本番運用まで段階的に収録
- rightmodel — タスクに応じた適切なClaudeモデルの選び方を学ぶ教材
- agent-decomposition — SkillsとMCPを使ったマルチエージェントシステムの分解・設計手法
- agents-that-remember — エージェントに記憶を持たせる実装パターン
- eval-driven-agent-development — 評価(Eval)を起点にしたエージェント開発フロー
- production-ready-agent — 実務を模したDeal Desk形式の本番運用ワークショップ
- research-desk — SEC提出書類やM&A分析を扱う調査エージェントの構築演習
- TypeScript/Python/JavaScriptなど複数言語にまたがる実装サンプルを収録

## トレンド入り理由の推測

このリポジトリは総スター数1.6kに対し本日だけで37個の新規スターを獲得しており、急激なバズというよりAnthropic公式アカウントの発信力を背景にした継続的な注目の高まりと見られます。Anthropicが主催する「Code with Claude」イベントの教材が無料公開されたことで、Claude Code・Claude Agent SDK・MCP(Model Context Protocol)といった最新のエージェント開発技術を体系的に学びたい開発者コミュニティから関心を集めています。

特に「エージェントに記憶を持たせる」「評価駆動でエージェントを開発する」「本番運用可能なエージェントを作る」といったテーマは、2025年後半から2026年にかけてAIエージェント開発における実務上の課題として広く議論されているトピックであり、公式チームが実際にどう解決しているかを学べる一次情報として価値が高い点がトレンド入りの背景と考えられます。フォーク数488という数字も、実際に手を動かして教材を試している開発者が多いことを示唆しています。
