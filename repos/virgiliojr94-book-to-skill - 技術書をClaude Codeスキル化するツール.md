## 概要

book-to-skillは、技術書のPDFやEPUB、DOCXなどのドキュメントを、GitHub Copilot CLIやAmp、Claude Codeといったエージェント向けの「スキル」に変換するツールです。単なる要約ではなく、著者の思考フレームワークや判断基準を抽出し、質問応答時にコンテキストへ本全体を流し込むのに比べて24〜51倍もトークン消費を削減できると謳っています。生成物はコアとなる概念を凝縮した`SKILL.md`（約4,000トークン）と、必要に応じて読み込まれる章ごとのファイル（各約1,000トークン）、用語集、パターン集、チートシートで構成されます。

RAG（検索拡張生成）がクエリ時に類似テキストチャンクを検索する方式であるのに対し、book-to-skillはコンパイル時に一度だけ深い分析を行い、著者の思考の枠組みや構造を抽出しておく点が本質的な違いです。PDF・EPUB・DOCX・Markdown・HTML・RTF・MOBI/AZW・プレーンテキストなど幅広い形式に対応し、`~/.copilot/skills/`や`~/.claude/skills/`などのスキルディレクトリへのクローン、またはpip経由のスタンドアロンCLIとして利用できます。ターゲットユーザーは、実務で参照する専門書の知識をAIコーディングエージェントに常時参照させたい開発者やチームです。なお、ツール自体は書籍の内容を一切同梱せず、ユーザーが所有するファイルの変換器としてのみ機能する点を明記しています。

---
## 主な機能・特徴

- 技術書PDF/EPUB/DOCX等をエージェント用スキルに自動変換
- コンパイル時の深い分析による著者フレームワーク・判断基準の抽出
- 本全体をコンテキストに流す方式比で24〜51倍のトークン削減を主張
- コア概念を凝縮した`SKILL.md`と章単位のオンデマンド読み込みファイルを生成
- 用語集・パターン集・チートシートの自動生成
- GitHub Copilot CLI・Amp・Claude Codeなど複数エージェントに対応
- pip経由のスタンドアロンCLIとしても利用可能
- 書籍コンテンツを同梱しないフェアユース設計
