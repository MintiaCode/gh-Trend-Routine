## 概要

Claude Code Templatesは、Anthropic製AIコーディングエージェント「Claude Code」をすぐに活用できる設定テンプレート・コンポーネントの総合コレクションです。AIエージェント、カスタムコマンド、設定、フック、MCP（外部サービス統合）、プロジェクトテンプレートなど100以上のコンポーネントを提供し、`npx claude-code-templates@latest`コマンドで対話的に選択・インストールできます。セキュリティ監査エージェント・Reactパフォーマンス最適化エージェントなどドメイン特化エージェント、`/generate-tests`・`/optimize-bundle`などのカスタムスラッシュコマンド、GitHub・PostgreSQL・Stripe・AWS連携のMCPサーバーなど多様なコンポーネントをワンコマンドで組み合わせられます。aitmpl.comのWebダッシュボードでブラウジング・管理も可能です。

---
## 主な機能・特徴

- 100以上のエージェント・コマンド・MCP・設定・フック・スキルのカタログ
- `npx claude-code-templates@latest`による対話的インストールと一括セットアップ
- GitHub・PostgreSQL・Stripe・AWS・OpenAIなど外部サービス統合MCPサーバー
- セキュリティ監査・フロントエンド開発・DBアーキテクトなどドメイン特化AIエージェント
- Claude Codeフック（pre-commitバリデーション等）によるワークフロー自動化
- Progressive DisclosureベースのReusableスキルシステム
- aitmpl.comでのWebダッシュボードによるコンポーネント管理（ベータ）
- Claude Code Analytics（リアルタイムセッション監視）機能搭載
