## 概要

dbt（data build tool）は、データアナリストやデータエンジニアがSQLのSELECT文を書くだけでデータウェアハウス上のデータ変換を実行できるフレームワークである。ソフトウェアエンジニアリングのベストプラクティス（バージョン管理、テスト、モジュール化）をデータ変換に適用するという思想のもと開発され、dbt Core v2.0ではPythonからRustへの完全書き換えが行われた。これにより、パース・コンパイル時間が劇的に高速化し、単一バイナリとしての配布が可能になりPythonランタイムが不要となった。Apache 2.0ライセンスで公開されており、Fusionエンジンの基盤としても機能する。データチームがSQLベースで信頼性の高いデータパイプラインを構築・テスト・ドキュメント化するための業界標準ツールである。

---
## 主な機能・特徴

- SQLベースの変換 — SELECT文を書くだけでテーブル・ビューを自動生成
- Rust製v2.0 — Pythonから完全書き換えによりパース・コンパイル速度が劇的に向上
- 単一バイナリ配布 — Python環境不要、インストールが大幅に簡素化
- Parquetアーティファクト — プロジェクト構造をクエリ可能な形式で出力
- データテスト — データ品質をSQLベースのテストで自動検証
- DAG管理 — モデル間の依存関係を自動解決・可視化
- マルチプラットフォーム — macOS/Linux/Windows（x86-64、ARM）対応
- ドキュメント自動生成 — 大規模プロジェクトにも対応する刷新されたドキュメントUI
