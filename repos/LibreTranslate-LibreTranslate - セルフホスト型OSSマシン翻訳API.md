# LibreTranslate/LibreTranslate

## 概要

LibreTranslateは、完全にセルフホスト可能な無料オープンソースのマシン翻訳APIです。Google翻訳やAzure翻訳のようなプロプライエタリサービスに依存せず、オープンソースのArgos Translateライブラリを翻訳エンジンとして採用しています。オフライン環境でも動作可能で、セットアップも容易に設計されています。データを外部サービスに送信する必要がないため、機密文書の翻訳やプライバシーに配慮が必要なシナリオに特に適しています。REST API形式で提供されるため、既存のアプリケーションやワークフローに簡単に統合でき、ドキュメントも充実しています。個人利用から企業のオンプレミス翻訳基盤まで、プライバシーとデータ主権を重視する幅広いユースケースに対応するセルフホスト型翻訳ソリューションです。

---
## 主な機能・特徴

- 完全セルフホスト — サーバーを自分で運用し、データを外部に送信しない
- オフライン対応 — インターネット接続なしで翻訳が動作
- REST API提供 — 標準的なHTTP APIで任意のアプリケーションと連携
- OSS翻訳エンジン — Argos Translateベースで完全なオープンソース構成
- 多言語対応 — 多数の言語ペアをサポート
- プライバシー保護 — プロプライエタリサービスへのデータ送信なし
- Docker対応 — コンテナで簡単にデプロイ・スケーリング可能
- コミュニティ駆動 — フォーラムとドキュメントによるサポート体制

## トレンド入り理由の推測

LibreTranslateが+83スターを獲得してトレンド入りしている背景には、データプライバシーとAI主権への関心の高まりがあります。EUのAI規制やデータ保護法制が強化される中、翻訳処理を外部のクラウドサービスに委ねることへの懸念が企業を中心に増大しており、完全にオンプレミスで動作するLibreTranslateは現実的な代替手段として注目されています。

また、AIエージェントやRAGパイプラインの構築が一般化する中で、多言語対応の必要性が増しています。LLMのプロンプトやドキュメントの翻訳をプライベートに処理できるAPIとして、LibreTranslateはAIワークフローの一部として組み込まれるケースが増えていると推測されます。特にMCPサーバーやAIエージェントのツールとして翻訳APIを統合する際、セルフホスト型であることは大きな利点です。

AGPL-3.0ライセンスによるコピーレフトの保証も、オープンソースコミュニティからの信頼を高め、Google翻訳への依存を脱却したいユーザーやプロジェクトからの継続的な支持を集めています。
