## 概要

ByteDance（TikTok開発元）が公開したオープンソースのマルチモーダルAIエージェント統合スタック。2つの主要プロジェクトで構成される。「Agent TARS」はCLIとWeb UIを備えた汎用マルチモーダルAIエージェントで、ターミナル・コンピュータ・ブラウザを自然言語で制御できる。「UI-TARS Desktop」はUI-TARSモデルを活用したデスクトップアプリで、ローカル・リモートのコンピュータやブラウザを自動操作できる。MCPツールとのシームレスな統合により、複数の最新AIモデルを接続できるインフラを提供し、人間のようなタスク完了ワークフローの実現を目指している。開発者・研究者・企業向けにGUI自動化エージェントを構築・展開するためのSDKも含まれており、AI活用の実用化を強力に後押しするプラットフォームとなっている。

---
## 主な機能・特徴

- Agent TARS CLI — CLIとWeb UIからマルチモーダルAIエージェントを操作・実行
- GUI Agent — 画面を視覚的に認識してUIを自動操作するGuiエージェント機能
- MCP統合 — 多様なMCPサーバーとシームレスに連携する拡張可能なツール基盤
- ローカル/リモート操作 — コンピュータとブラウザのローカル・リモート双方の制御に対応
- マルチモデル対応 — 最前線のAIモデルを接続・切り替えられるインフラ設計
- UI-TARS SDK — GUI自動化エージェント構築のためのクロスプラットフォームSDK
- ストリーミングサポート — シェルコマンド・マルチファイル表示のリアルタイムストリーミング
- サンドボックス環境 — AIO Agent Sandboxによる隔離されたツール実行環境
