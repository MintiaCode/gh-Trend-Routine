## 概要

free-llm-api-resourcesは、APIを通じて無料または試用で利用できるLLM（大規模言語モデル）推論サービスを網羅的にまとめたリポジトリです。OpenRouter・Google AI Studio・NVIDIA NIM・Mistral・Groq・HuggingFaceなどの無料枠サービスから、Fireworks・Baseten・Modal・Scalewayなどのトライアルクレジットサービスまでをカバーしています。各サービスの利用可能モデル・リクエスト制限（分あたり・日あたり）・データ学習への使用有無・電話番号認証の要否などの情報も記載されており、用途に合った無料LLM APIを素早く見つけることができます。プロジェクトではリバースエンジニアリングされた非公式チャットボットAPIは対象外とし、正規の無料枠のみを掲載するという方針を取っています。個人開発者・研究者・学習者がコストなしにLLMをAPI経由で試したいときの最初の参照先として広く使われています。

---
## 主な機能・特徴

- 無料枠サービスの網羅 — OpenRouter・Groq・AI Studioなど主要サービスの無料枠情報
- レート制限情報 — 分あたり・日あたりのリクエスト上限を整理
- トライアルクレジット情報 — 初期クレジット付きサービスの比較（$1〜$30相当）
- データ利用ポリシー — 学習データへの使用有無を明記
- 認証要件の整理 — 電話番号認証等の要件を記載
- 継続的な更新 — 400以上のコミットによるアクティブメンテナンス
- 正規サービスのみ掲載 — リバースエンジニアリング系は除外

## トレンド入り理由の推測

20,400スターという大型リポジトリでありながら今日255スターを獲得しており、これはLLM APIのコストに悩む開発者コミュニティで継続的に参照・共有されていることを示しています。2026年においてGPT-4やClaude Opus・Gemini Ultraなどの高性能モデルのAPI費用は依然高水準であり、無料・低コストで試せるリソースへの需要は常に高い状態です。

新しい無料枠サービスやトライアルクレジットの追加・変更があるたびにリポジトリが更新され、その更新情報がSNSや技術系Discordサーバーでシェアされてトラフィックとスターのスパイクを生みます。特にGroqの無料枠やScalewayの100万トークン無料枠といった太っ腹な提供が話題になるたびに注目が集まります。

また、AIハッカソンや学習目的でLLMを試したい学生・エンジニアにとって、このリストは「まず最初に見るべきブックマーク」として機能しており、技術ブログやYouTubeの「AIエージェント構築入門」系コンテンツで繰り返し紹介されることで継続的なスターを獲得しています。
