## 概要

claude-howtoは、Anthropic製AIコーディングエージェント「Claude Code」の使い方を10モジュールに分けて視覚的・実践的に解説するオープンソースガイドです。公式ドキュメントが「機能の説明」にとどまるのに対し、このガイドは「機能を組み合わせてどう使うか」に焦点を当て、コピー＆ペーストで使えるテンプレート、Mermaidダイアグラム、実例を豊富に提供します。スラッシュコマンドから始まり、メモリシステム、スキル、サブエージェント、MCPプロトコル、フック、プラグイン、高度な自動化まで、初心者から上級者まで対応した合計11〜13時間の学習パスを提供します。最新のClaude Code v2.1.160に対応しており、オフラインEPUB生成機能も備えています。

---
## 主な機能・特徴

- 10モジュール構成 — スラッシュコマンドから高度なエージェントチームまで段階的に学習
- コピー可能テンプレート — CLAUDE.mdや設定ファイルをそのまま使えるサンプル集
- Mermaidダイアグラム — 機能の仕組みを視覚的に理解できるフロー図
- サブエージェント解説 — 複数AIエージェントの協調動作を実例付きで説明
- MCPプロトコルガイド — 外部ツール統合の仕組みと実装方法を解説
- フック（Hooks）入門 — イベント駆動自動化の設定と活用法を網羅
- オフラインEPUB生成 — インターネット不要で閲覧できる形式に変換可能

Claude Codeのユーザーベースが急速に拡大している2026年において、「使い方を体系的に学べるリソース」へのニーズは非常に高い。公式ドキュメントは機能を列挙するが実践的な組み合わせ方を示さないという不満がコミュニティで広く共有されており、claude-howtoはその空白を埋めることで35,700という高い総スター数を積み上げてきた。

35,700という総スター数と393という今日の増加数は、このリポジトリが成熟しつつも継続的に新規ユーザーを引きつけていることを示す強いシグナルだ。Claude Codeを使いこなしたいというニーズは世界中にあり、視覚的でわかりやすい解説が日本語・英語話者を問わず広く共有されている。「ゼロから学べる + すぐ使えるテンプレート」という組み合わせが長期的なバイラル効果をもたらしている。
