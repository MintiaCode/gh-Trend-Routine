## 概要

Pi Webは、「pi」というAIコーディングエージェントのためのブラウザベースの管理画面を提供するツールである。piはCLIで動作するAIコーディングエージェントだが、ターミナル上でのセッション管理には限界があり、複数プロジェクトにまたがる会話履歴の把握や、過去のやりとりからの分岐、ファイルの参照などが煩雑になりがちである。Pi Webはローカルに保存されたpiのセッションファイル(~/.pi/agent/sessions/)を読み込み、プロジェクトごとに整理されたセッションブラウザ、リアルタイムのチャットビュー、モデルやAPIキーの設定画面、スキル管理、そしてソースコードやドキュメントのプレビュー機能をひとつのWebアプリケーションとして提供する。Next.jsとTypeScriptで構築されており、Server-Sent Eventsを用いてエージェントとの対話をリアルタイムに反映する。npxコマンド一つでローカルサーバーとして起動でき、ブラウザからlocalhost経由でアクセスする設計のため導入の手間も少ない。対象ユーザーはCLIベースのAIコーディングエージェントを日常的に使う開発者で、特に複数プロジェクトを並行して進めるチームや、セッション履歴を可視化して振り返りたいエンジニアにとって有用なツールとなっている。

---
## 主な機能・特徴

- セッションブラウジング — プロジェクトごとにpiのセッション履歴を整理して閲覧できる
- リアルタイムチャット — ツール呼び出しを含む会話をブラウザ上でストリーミング表示
- セッションの分岐・フォーク — 過去のメッセージから会話を分岐して新しいセッションを作成
- Git worktree切り替え — サイドバーから作業ツリーを直接切り替え可能
- ファイルプレビュー — ソースコードや画像・PDFなどをサイドバイサイドで確認
- モデル・APIキー管理 — UI上でモデル設定、APIキー、スキルの有効/無効を管理
- セッション状態の可視化 — コンテキスト使用量やコストをリアルタイムに表示
- npx実行対応 — `npx @agegr/pi-web@latest` で即座に起動可能
