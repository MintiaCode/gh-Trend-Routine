## 概要

無料または低コストのLLMバックエンドを使ってClaude Code CLIおよびVSCode拡張機能を利用するための軽量プロキシサーバーです。NVIDIA NIM（毎分40リクエスト無料）、OpenRouter（数百のモデルに対応）、DeepSeek、LM Studio、llama.cpp、Ollama（完全ローカル）の6種類のプロバイダーに対応しています。環境変数2つを設定するだけでClaude CodeのAPIコールをリダイレクトできるため、Claude Code CLI本体やVSCode拡張機能の変更は一切不要です。Opus・Sonnet・Haiku向けのモデルマッピングやシンキングトークンのサポートも含まれており、コストを抑えながらClaude Codeのフルエクスペリエンスを享受したい開発者向けのソリューションです。

---
## 主な機能・特徴

- ゼロコスト — NVIDIA NIMで毎分40リクエスト無料、OpenRouterで無料モデルも利用可能
- ドロップイン対応 — 環境変数2つの設定のみでClaude Code CLI・VSCode拡張をそのまま利用
- 6プロバイダー対応 — NVIDIA NIM・OpenRouter・DeepSeek・LM Studio・llama.cpp・Ollama
- モデルマッピング — Opus/Sonnet/Haikuを異なるプロバイダー・モデルに自由にルーティング
- シンキングトークン対応 — thinkingタグとreasoningコンテンツをネイティブのClaude形式に変換
- ローカルLLM完全サポート — LM StudioやOllamaを使って完全オフラインでの運用が可能
- APIポート8082番 — プロキシはポート8082で起動しANTHROPIC_BASE_URLで接続

## トレンド入り理由の推測

AnthropicのAPIキーは有料であることから、Claude Codeを無料で使用できるプロキシは多くの開発者にとって非常に魅力的です。特に2026年においてClaude Codeが広く普及する中、コスト面での参入障壁を下げるこのツールへの需要は急速に増大しており、「無料でClaude Codeを使いたい」という開発者の強いニーズを正面から捉えています。

直近の2026-04-26に更新が行われており、openclaw等の類似ツールが同じくトレンド入りするタイミングと重なり相乗効果が働いたと考えられます。「free-claude-code」というリポジトリ名のわかりやすさも、検索からの流入を大幅に増加させた要因です。

さらに、NVIDIA NIMの無料枠やOllama/LM Studioとの組み合わせによって完全無料での運用が実現できる点が技術者コミュニティで注目されています。API互換性を保ちながらプロバイダーを柔軟に切り替えられる設計の巧みさも、エンジニアの高い評価を集めています。
