## 概要

Page Agentは、Alibaba発のJavaScriptベースのインページGUIエージェントである。ブラウザ拡張やPython環境、ヘッドレスブラウザを一切必要とせず、Webページ内のJavaScriptだけで自然言語によるUI操作を実現する。スクリーンショットやマルチモーダルLLMに依存せず、テキストベースのDOM操作を採用しているため、軽量かつ高速に動作する。SaaS製品へのAIコパイロット組み込み、ERP/CRMのスマートフォーム入力、アクセシビリティ向上、マルチページエージェントなど幅広いユースケースに対応する。npmパッケージとして提供され、数行のコードで既存のWebアプリケーションに統合できる手軽さが特徴だ。LLMは任意のモデルを持ち込めるBYOLLM方式を採用しており、Chrome拡張やMCPサーバーによるブラウザ外からの制御にも対応している。

---
## 主な機能・特徴

- インページ動作 — ブラウザ拡張やPython不要、JavaScriptのみでWebページ内で完結
- テキストベースDOM操作 — スクリーンショット不要で軽量・高速な自然言語UIコントロール
- BYOLLM対応 — Qwen、OpenAI等任意のLLMプロバイダーを持ち込み可能
- ワンライン統合 — scriptタグ1行またはnpmインストールで即座に導入
- Chrome拡張連携 — マルチタブ・マルチページにまたがるエージェント操作を実現
- MCPサーバー — 外部エージェントクライアントからのブラウザ制御に対応
- SaaSコパイロット — 既存プロダクトにAIコパイロットを数行で組み込める
- アクセシビリティ — 自然言語・音声コマンドによるWebアプリのバリアフリー化
