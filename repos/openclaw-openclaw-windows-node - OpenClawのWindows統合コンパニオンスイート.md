## 概要

openclaw-windows-nodeはOpenClaw AI個人アシスタントのWindows専用コンパニオンスイートです。WinUI 3製のシステムトレイアプリ（OpenClaw.Tray.WinUI）、共有ゲートウェイクライアントライブラリ、CLI検証ツールの3つのプロジェクトから構成されます。Windows 11スタイルのモダンUIでAIゲートウェイに接続し、グローバルホットキー（Ctrl+Alt+Shift+C）によるクイック送信、WebView2によるエンベデッドWebチャット、Windowsトースト通知、Telegram/WhatsAppチャンネル制御など多彩な機能を提供します。ノードモードでは、AIエージェントがWindowsを直接操作するためのコマンド（スクリーンショット・カメラ・音声合成・コマンド実行など）をリモートから受け付けられるようになります。Scott HanselmanとMoltyが開発した本格的なWindowsネイティブAIエージェント統合スイートです。

---
## 主な機能・特徴

- システムトレイアプリ — WinUI 3製Windows 11スタイルUI、ダーク/ライトモード対応
- クイック送信 — Ctrl+Alt+Shift+Cグローバルホットキーでワンタッチメッセージ送信
- ノードモード — AIエージェントからのスクリーン・カメラ・音声合成・コマンド実行受付
- WebView2チャット — ネイティブウィンドウでのエンベデッドAIチャット
- チャンネル制御 — Telegram/WhatsAppチャンネルのメニューから直接開始/停止
- オンボーディングウィザード — 6画面の初回セットアップガイド
- 自動アップデート — GitHub Releasesからの自動更新機能
