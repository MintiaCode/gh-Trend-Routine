# OtterMind/Chat2DB

▎ AI搭載のDB管理SQLクライアント

ライセンス: Apache-2.0ベース(v5.3.0以降は独自条件付き)
言語: Java

トレンド順位: #16 (2026-07-24)

## 概要

Chat2DBは、開発者・DBA・データアナリストを対象とした無料のクロスプラットフォームAI搭載データベースクライアントです。MySQL・PostgreSQL・Oracle・SQL Server・ClickHouse・MongoDB・Redis・SQLite・Snowflake・BigQueryなど30種類以上のデータベースをプラグイン経由でサポートし、DataGripやNavicat、DBeaverといった既存の商用・OSSクライアントの代替となることを狙っています。最大の特徴は、自前で用意したAIモデルを接続してSQLを自然言語から生成・説明・最適化できる点で、いわゆるText-to-SQL体験をローカル環境で完結させられます。アプリケーションはローカルマシン上で完全に動作するシングルユーザー設計となっており、認証やユーザー管理の仕組みを持たない代わりに、外部ネットワークに公開しないことを前提としたセキュリティモデルを採用しています。SQL編集・補完・実行履歴に加え、ダッシュボードやER図によるデータ可視化、データのインポート/エクスポート、MCP対応のCLIツールも提供され、ローカルからチームでのデータ分析まで幅広い用途をカバーします。

---
## 主な機能・特徴

- 30以上のDB対応 — MySQL、PostgreSQL、Oracle、ClickHouse、MongoDBなどプラグイン経由で幅広くサポート
- AIアシスタント — 手持ちのAIモデルを接続し自然言語でSQLを生成・説明・最適化
- SQLワークスペース — 補完、フォーマット、実行履歴を備えたエディタ
- データ管理 — テーブル・オブジェクトのメタデータ閲覧とDDL/DML編集
- ダッシュボード&ER図 — データの可視化と構造把握を支援
- インポート/エクスポート — データの一括入出力に対応
- MCP対応CLI — オープンソースのコマンドラインツールも別リポジトリで提供
- Docker対応 — 暗号化キー管理を含むコンテナデプロイをサポート
