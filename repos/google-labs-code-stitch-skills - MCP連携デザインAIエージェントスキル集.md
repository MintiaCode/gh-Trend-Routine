## 概要

stitch-skillsは、Googleが提供するデザインツール「Stitch」のMCP(Model Context Protocol)サーバーと連携して動作する、AIエージェント向けスキル集です。Agent Skillsというオープンな標準規格に準拠しており、Claude Code、Cursor、Gemini CLI、Antigravityなど複数のコーディングエージェントから共通の形式で利用できる点が特徴です。従来、UIデザインからコードへの変換や新規画面のデザイン生成は人手による試行錯誤が必要でしたが、本ライブラリはそれらの作業をAIエージェントに委譲可能な「スキル」として体系化し、標準化された手順で呼び出せるようにすることでこの課題を解決します。Design・Build・Utilitiesという3つのプラグイン群に分かれており、フロントエンドコードからデザインを起こす、テキストから新規画面を生成する、デザインをReactやReact Native、shadcn/uiのコードに変換するといった機能を提供します。想定ユーザーは、AIエージェントを使ってプロダクト開発のデザインからコード実装までを高速に回したいプロダクトデザイナーやフロントエンドエンジニア、AIエージェント基盤を構築する開発者です。

---
## 主な機能・特徴

- Design Plugin — フロントエンドコードからデザインを起こす、テキストから新規画面を生成するなど6つのデザイン関連スキルを提供
- Build Plugin — Stitchのデザインを React、React Native、shadcn/ui向けのコードや動画に変換するコード生成機能
- Utilities Plugin — デザイン仕様書生成、プロンプト強化、Webサイト構築自動化などの補助ツール群
- Agent Skills標準準拠 — Claude Code、Cursor、Gemini CLI、Antigravityなど複数のコーディングエージェントで共通利用可能
- npx skills add対応 — 個別スキルをコマンド一つで追加できる柔軟なインストール方式
- マーケットプレイス一括導入 — CLIやUIからStitch Skillsマーケットプレイス全体を追加し、必要なプラグインを選択導入可能
- Stitch MCPサーバー前提設計 — GoogleのStitchデザインツールをMCP経由でエージェントに接続する構成
- 標準化されたプロジェクト構造 — SKILL.md、検証用スクリプト、ナレッジベース、参照例を含む統一ディレクトリレイアウト
