# puppeteer/puppeteer

▎ Chromeを高レベルAPIで操作するブラウザ自動化

ライセンス: Apache-2.0
言語: TypeScript
スター数: ⭐ 94,600 (+59 今日)
トレンド順位: #14 (2026-06-14)

---
## 概要

PuppeteerはChromeまたはFirefoxをDevTools Protocol（DTP）またはWebDriver BiDiを通じて高レベルAPIで制御するJavaScriptライブラリです。GoogleのChromeチームが開発・維持しており、ヘッドレス（UIなし）またはヘッドフルモードでのブラウザ自動化を実現します。Webスクレイピング、スクリーンショット・PDF生成、E2Eテスト、フォーム送信、SPA（シングルページアプリケーション）のクローリング、パフォーマンス測定など幅広いユースケースに対応しています。npmでインストールするだけでChromeが自動ダウンロードされ、すぐに使い始められます。さらにChromeDevTools MCP ServerをベースにAIエージェントのブラウザ操作も可能で、WebMCPなど次世代のWeb自動化APIもサポートしています。

---
## 主な機能・特徴

- Chrome/Firefox対応 — DevTools ProtocolとWebDriver BiDi両方をサポート
- ヘッドレス動作 — UIなしでのバックグラウンドブラウザ操作が可能
- スクリーンショット・PDF生成 — Webページを画像やPDFとして保存
- フォーム操作自動化 — クリック、入力、ファイルアップロードなどを完全自動化
- ネットワークインターセプト — HTTPリクエスト・レスポンスの監視・変更が可能
- MCP Server対応 — AIエージェントとのブラウザ連携をMCPプロトコルでサポート
- Node.js/TypeScript対応 — npm経由でインストール、TypeScriptでの型安全な利用が可能

## トレンド入り理由の推測

Puppeteerが今日59スターを獲得した背景には、AIエージェントによるブラウザ自動化（Computer Use/Browser Use）への関心急増があります。2026年現在、LLMベースのAIエージェントがWebブラウザを操作するユースケースが爆発的に増加しており、Puppeteerはその基盤技術として再注目を集めています。

READMEでMCP（Model Context Protocol）サーバーとのインテグレーションが明記されており、AIエージェントがChromeを操作するための標準インターフェースとして採用が進んでいます。AnthropicのClaude、OpenAIのChatGPTなどのエージェント機能拡張においてPuppeteerベースのツールが多数使われており、AIコミュニティからの関心が高まっています。

94,600スターという圧倒的な総スター数を持ちながら、WebMCPなど新しいAPIへの対応を継続的に行っていることから、長年のユーザーがアップデートを確認しつつスターを付ける傾向があります。browser-useやPlaywrightなどの競合ツールとの比較記事が定期的に公開されることも、Puppeteerへの流入を促進しています。
