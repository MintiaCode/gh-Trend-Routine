## 概要

Codex CLI は OpenAI が開発する、ローカル端末上で動作するコーディングエージェントです。ターミナルから自然言語で指示を出すだけで、コードの生成・修正・調査・リファクタリングなどをエージェントが自律的に実行してくれます。VS Code、Cursor、Windsurf といった主要エディタへの統合や、`codex app` コマンドによるデスクトップアプリ体験も提供されており、クラウド版の Codex Web（chatgpt.com/codex）とも連携できます。認証は ChatGPT アカウント（Plus・Pro・Business・Edu・Enterprise の各プラン）または API キーで行え、開発者はサブスクリプションの範囲内で追加コストなくエージェントを利用可能です。インストールは curl/PowerShell スクリプト、npm、Homebrew、GitHub Releases から選べ、Rust で実装されているため軽量かつ高速に動作します。ターミナル中心のワークフローを崩さずに、AIによる開発支援を受けたいエンジニアに向いたツールです。

---
## 主な機能・特徴

- ローカル実行エージェント — 端末上で自然言語指示からコード生成・修正・調査を自律実行
- マルチプラットフォーム対応 — macOS（Apple Silicon/x86_64）、Linux、Windows 向けバイナリを提供
- エディタ統合 — VS Code、Cursor、Windsurf にIDE拡張として組み込み可能
- デスクトップアプリ — `codex app` コマンドでGUI体験を提供
- クラウド版との連携 — ブラウザで動くCodex Webへシームレスに移行可能
- 柔軟な認証方式 — ChatGPTアカウントまたはAPIキーでサインイン
- 複数のインストール手段 — curl/PowerShellスクリプト、npm、Homebrew、GitHub Releasesに対応
- Rust製の軽量設計 — 高速起動と省リソースを実現
