## 概要

CodeGraphは、Claude Codeの拡張ツールとして開発されたローカル完結型のコード知識グラフシステムです。コードベースをtree-sitterでAST解析し、SQLiteデータベースに事前インデックスとして保存することで、Claude Codeのツール呼び出しを最大94%削減、コード探索速度を最大82%高速化します。外部サービスへの依存やAPIキーは一切不要で、すべてのデータがローカルに保存されます。

TypeScript、Python、Go、Rust、Java、C#など19以上の言語をサポートし、Django、Flask、Express、Laravelなど主要フレームワークのルート構造も認識します。ネイティブOSのファイル監視機能によりコードベースの変更を自動検知し、2秒のデバウンスで常に最新の状態に保ちます。

実際のVS Code TypeScriptコードベースでのテストでは、CodeGraph有りで3回・17秒だったツール呼び出しが、CodeGraph無しでは52回・1分37秒かかっていたという大幅なパフォーマンス改善が実証されています。Claude Codeで大規模コードベースを効率よく探索したい開発者が主な対象ユーザーです。

---
## 主な機能・特徴

- スマートコンテキスト構築 — エントリーポイント・関連シンボル・コードスニペットを単一ツール呼び出しで返却
- 全文検索 — FTS5を使った高速シンボル検索でコードベース全体を即時ルックアップ
- 影響範囲分析 — シンボルの呼び出し元・呼び出し先・変更影響半径をトレース
- 自動同期 — ネイティブOSファイルウォッチャーと2秒デバウンスでグラフを常に最新化
- 19以上の言語対応 — TypeScript・Python・Go・Rust・Java・C#など主要言語を網羅
- フレームワーク認識 — Django・Flask・Express・LaravelなどのルートパターンをAIが把握
- 100%ローカル動作 — 外部APIキーや通信不要、すべてのデータがローカルSQLiteに保存
