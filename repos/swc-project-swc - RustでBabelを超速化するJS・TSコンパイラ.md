# swc-project/swc

▎ RustでBabelを超速化するJS・TSコンパイラ

---
## 概要

SWC（Speedy Web Compiler）は「Webの開発を高速化する」を掲げるRust製のTypeScript・JavaScriptコンパイラです。BabelやTypeScriptコンパイラの代替として、従来比で数十倍の変換速度を実現します。RustライブラリとしてもJavaScriptパッケージとしても利用でき、Next.js・Parcel・Deno・Viteなど主要なフロントエンドフレームワーク・バンドラーの内部コンパイラとして採用されています。ECMAScriptのパース・変換・コード生成を担い、TypeScript、JSX、最新のES構文をダウンコンパイルする機能を持ちます。Node v10以上で利用可能で、フロントエンドのビルドパイプラインを高速化したいチームにとって、ほぼゼロ設定で導入できる実用的な選択肢です。

---
## 主な機能・特徴

- Babelと比較して数十倍高速なTypeScript・JavaScript変換処理
- TypeScript、JSX、最新ECMAScript構文のトランスパイル対応
- RustライブラリとJavaScriptパッケージの両方として利用可能
- Next.js・Parcel・Deno等の主要フレームワークへの組み込み採用実績
- 高精度なECMAScriptパーサーによる正確な構文解析
- プラグインシステムによる変換ルールの拡張性
- Node v10+対応の広い互換範囲と806件以上のリリース実績
