# firecrawl/firecrawl

▎ 大規模Web検索・スクレイピングAPI基盤

ライセンス: AGPL-3.0
言語: TypeScript
スター数: ⭐ 137064 (+736 今日)
トレンド順位: #13 (2026-06-22)

---
## 概要

Firecrawlは、Web全体を大規模に検索・スクレイピング・操作するためのAPIプラットフォームである。JavaScript多用ページを含むWebの96%をカバーし、P95レイテンシ3.4秒という高速性を実現している。取得したWebコンテンツをクリーンなMarkdown、構造化JSON、スクリーンショットなどLLMに最適な形式に変換し、AIエージェントやアプリケーションへの統合を容易にする。プロキシローテーション、レート制限、JSブロックコンテンツの処理などの複雑な処理を自動で行い、設定不要で利用できる。MCPクライアント対応により、AIエージェントとのワンコマンド接続も可能である。PDF・DOCXなどのメディアパースや、クリック・スクロールなどのページ操作機能も備え、包括的なWeb データ取得基盤として機能する。

---
## 主な機能・特徴

- Search — Web検索と検索結果の全ページコンテンツ取得
- Scrape — 任意URLをMarkdown・HTML・スクリーンショット・構造化JSONに変換
- Interact — ページスクレイプ後にAIプロンプトやコードで操作
- Agent — 必要なデータを記述するだけの自動データ収集
- Crawl — 単一リクエストでWebサイト全URLをスクレイピング
- Map — Webサイトの全URL構造を即座に発見
- Batch Scrape — 数千URLの非同期一括スクレイピング
- MCP対応 — AIエージェントやMCPクライアントとワンコマンド接続

## トレンド入り理由の推測

Firecrawlは既に137,000以上のスターを持つ大規模プロジェクトだが、本日736スターを獲得してトレンド入りした。AIエージェントがWeb上の情報を取得・活用する需要が爆発的に増加する中、Firecrawlは「AIエージェントのためのWebアクセス層」としてのポジションを確立している。MCPプロトコル対応やInteract機能の追加など、エージェントファースト設計が時代のニーズに合致している。

pushed_atが本日であることから、新機能リリースや性能改善が行われた可能性がある。RAG（Retrieval-Augmented Generation）パイプラインの構築においてWeb情報の構造化取得は不可欠であり、FirecrawlのMarkdown変換やJSON抽出機能はLLMトークンの効率的利用に直結する。競合のCrawl4AIやJinaなどとの差別化として、96%のWeb対応率やP95 3.4秒のレイテンシという実績値を打ち出している点も、エンタープライズ採用を後押しする要因となっている。
