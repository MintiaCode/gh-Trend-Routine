# ChromeDevTools/chrome-devtools-mcp

▎ AIエージェント用Chrome操作MCPサーバー

ライセンス: Apache-2.0
言語: TypeScript
スター数: ⭐ 38755 (+159 今日)
トレンド順位: #7 (2026-05-09)

---
## 概要

Google公式のChromeDevToolsリポジトリが公開した、AIコーディングエージェント向けMCPサーバー。Gemini・Claude・Cursor・GitHub Copilotなどの各種AIエージェントがChrome DevToolsの機能を通じてブラウザを直接操作・検査できるようにする。Puppeteerをベースとした信頼性の高いブラウザ自動化に加え、ネットワークリクエストの分析・スクリーンショット取得・ブラウザコンソールメッセージの確認・パフォーマンストレースの記録など、Chrome DevToolsが持つ強力なデバッグ機能をAIエージェントに開放する。`npx`コマンド1行で導入できるシンプルなセットアップが特徴で、スリムモード・ヘッドレスモードにも対応している。

---
## 主な機能・特徴

- ブラウザ制御 — Puppeteerを用いてAIエージェントがChromeブラウザを直接操作・自動化
- パフォーマンス分析 — DevToolsトレースを記録してパフォーマンスのボトルネックを特定
- ネットワーク検査 — HTTPリクエスト・レスポンスの詳細な分析をエージェントが実行
- コンソールデバッグ — ソースマップ付きスタックトレースでブラウザコンソールメッセージを確認
- スクリーンショット — ブラウザの現在状態を画像として取得しAIが視覚的に確認・分析
- マルチエージェント対応 — Gemini・Claude・Cursor・Copilotなど主要AIエージェントをサポート
- スリム/ヘッドレスモード — 軽量な基本操作から高度なDevTools機能まで段階的に利用可能

## トレンド入り理由の推測

chrome-devtools-mcpはGoogle公式のChromeDevToolsリポジトリから提供されているMCPサーバーであり、38,755スターという大規模なコミュニティを持つ。本日もアップデートがプッシュされており、引き続き159スターを獲得した。GoogleがMCPという業界標準プロトコルを採用してAIエージェント向けDevTools連携ツールを公式提供するという事実は、エージェント時代における大企業の標準化への参入を示すものとして注目を集めている。

Cursor・Copilot・Claude Codeなどのコーディングエージェントが爆発的に普及する中、「AIエージェントがブラウザを操作してデバッグできる」という能力は開発者の強いニーズを満たす機能である。E2Eテスト自動化・UIデバッグ・パフォーマンス最適化の文脈で、AIエージェントにブラウザの「目と手」を与えるツールとして高く評価されている。
