# aaif-goose/goose

▎ ローカル動作のオープンソースAIエージェント

ライセンス: Apache-2.0
言語: Rust
スター数: ⭐ 47400 (+338 今日)

---
## 概要

Gooseは、デスクトップアプリ・CLI・APIとして動作するオープンソースのAIエージェントです。コード生成だけにとどまらず、ソフトウェアのインストール、コマンド実行、ファイル編集、テストの実行まで幅広いタスクを自律的に処理します。Rust製のネイティブアプリケーションとしてmacOS・Linux・Windowsに対応し、高いパフォーマンスと移植性を実現しています。15以上のLLMプロバイダー（Anthropic、OpenAI、Googleなど）に対応し、ユーザーは既存のAPIキーをそのまま利用できます。Model Context Protocol（MCP）を通じて70以上の拡張機能をサポートしており、ワークフローの自動化から複雑な開発タスクまで柔軟に対応します。もともとBlock（旧Square）が開発したプロジェクトで、現在はLinux Foundation傘下のAgentic AI Foundation（AAIF）に移管され、オープンなガバナンスのもとで開発が継続されています。

---
## 主な機能・特徴

- クロスプラットフォーム対応 — macOS・Linux・Windows向けネイティブデスクトップアプリとCLIを提供
- マルチLLMサポート — Anthropic、OpenAI、Google、Ollamaなど15以上のAIプロバイダーに接続可能
- MCP拡張エコシステム — Model Context Protocolで70以上の拡張機能をサポート
- 自律的タスク実行 — インストール・実行・編集・テストをエージェントが自動処理
- Rust製高パフォーマンス — ネイティブバイナリによる軽量・高速な動作
- ACP対応 — Agent Communication Protocolによるエージェント間連携が可能
- オープンガバナンス — Linux Foundation / AAIFによる中立的なOSS運営体制

## トレンド入り理由の推測

本日338スターを獲得しており、スター総数47,400に対してもかなりの伸び率です。Block（旧Square）からLinux Foundation傘下のAgentic AI Foundation（AAIF）への移管という組織的な転換が大きな注目を集めた可能性があります。大企業のプロジェクトがオープンな財団に移管されることでコミュニティの期待と信頼が高まり、新規スターが急増したと考えられます。

AIエージェントフレームワーク市場が急成長する中で、Gooseはローカル実行・マルチLLM・MCP対応という三拍子が揃った希少なツールとして差別化されています。特にMCPエコシステムの急拡大とともに、MCPをネイティブサポートするエージェントとして開発者コミュニティから注目が集まっています。また「コード提案にとどまらない」という設計思想が、CopilotやCursorとの差別化として訴求されています。

Rust製という技術選定も重要な要因です。高パフォーマンスと低メモリ消費が求められるデスクトップAIエージェントとしてRustは理想的な選択であり、Rustコミュニティからの関心も集めています。AI×Rust×クロスプラットフォームという組み合わせが、幅広い技術者層のスターを呼び込んでいます。
