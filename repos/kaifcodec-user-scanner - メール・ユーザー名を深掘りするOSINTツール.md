# kaifcodec/user-scanner

▎ メール・ユーザー名を深掘りするOSINTツール

ライセンス: MIT
言語: Python

## 概要

user-scannerは、メールアドレスとユーザー名の両方を対象にした「2-in-1」型のOSINT（オープンソースインテリジェンス）調査スイートです。175以上のメール連携サイトと290以上のユーザー名プラットフォームを合わせて465以上のスキャンベクトルを備え、対象のデジタルフットプリントをマッピングし、行動傾向や興味関心、アカウント登録状況を数秒で洗い出すことができます。アバターやプロフィール文、フォロワー数、UID、出品者ステータスなどのリッチなメタデータを収集するほか、初期スキャンで得たハンドル名やプロフィールリンク、露出したメールアドレスを起点に二次的な調査対象へ自動的にピボットする機能も持ちます。Claude DesktopやCursorなどからMCP経由で呼び出せるAIエージェント連携や、インフォスティーラー型マルウェアの流出ログを検索するHudson Rock連携も搭載しており、レッドチーム・ペネトレーションテスター・脅威インテリジェンス調査員・セキュリティリサーチャーを主な対象としています。

---
## 主な機能・特徴

- 465以上のスキャンベクトル — メール175+・ユーザー名290+のプラットフォームを横断調査
- リッチなメタデータ収集 — アバター・自己紹介・フォロワー数・UIDなどを自動収集
- クロススキャン・ピボットエンジン — 発見したハンドルやメールを起点に二次調査へ自動展開
- MCPサーバー対応 — Claude DesktopやCursor等のAIエージェントから自律スキャンを実行可能
- Hudson Rock連携 — インフォスティーラー侵害ログとの照合で優先度の高い対象を特定
- 高並列エンジン — httpxとcurl_cffiによるTLSフィンガープリント偽装で高速並列処理
- エイリアス生成機能 — タイポスクワッティングや別名候補をワイルドカードで自動生成
- 多形式レポート出力 — PDF・JSON・CSVでのエクスポートによりパイプライン連携が容易

## トレンド入り理由の推測

OSINTツールは常にセキュリティ・レッドチームコミュニティから一定の関心を集めるジャンルですが、今日184スターという急伸を見せている背景には、MCPサーバー対応によるAIエージェント連携という比較的新しい要素が寄与していると考えられます。Claude DesktopやCursorなどのAIコーディング・エージェント環境からOSINT調査を自律的に実行できる点は、従来型のCLIツールにはない新規性であり、AIエージェント活用に関心の高い層からの注目を集めやすい構造です。

また、Hudson Rockのインフォスティーラー侵害ログ連携により、単なるアカウント存在確認にとどまらず「実際に漏洩した認証情報との相関分析」まで踏み込んでいる点も、脅威インテリジェンス分野での実用性を高めており、レッドチームやセキュリティリサーチャーの実務ツールとして紹介・拡散されやすい要因になっていると推測されます。

スポンサー欄に複数のOSINT関連サービスが名を連ねていることからも、この分野のコミュニティで一定の認知と評価を確立していることがうかがえ、Discordコミュニティの活性化やPyPI経由でのインストールのしやすさも、継続的なスター増加を後押ししていると考えられます。
