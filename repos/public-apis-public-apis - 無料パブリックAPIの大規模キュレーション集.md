## 概要

public-apisは、動物・アニメ・ブロックチェーン・書籍・金融・天気・ゲームなど40以上のカテゴリにわたる無料パブリックAPIを網羅したコミュニティキュレーション集です。GitHubで42万以上のスターを持つ超人気リポジトリで、開発者がプロジェクトに利用できる無料APIを素早く探せる場として長年親しまれています。各APIには認証方式（APIキー・OAuth・不要）・HTTPS対応・CORS互換性などのメタデータが付記されており、開発者が用途に合ったAPIを素早く絞り込めます。世界中のコミュニティメンバーが継続的にメンテナンスしており、常に最新のAPIが追加されています。

---
## 主な機能・特徴

- 40以上のカテゴリ — 動物・金融・天気・ゲーム・地理・認証など幅広いAPI分類
- 認証情報付き — 各APIの認証方式（apiKey/OAuth/なし）を一覧で確認可能
- HTTPS・CORS表示 — セキュリティ・ブラウザ互換性の確認も一目でわかる
- コミュニティ維持 — PRとIssueで誰でも貢献でき常に最新情報を維持
- Discordサポート — 活発なコミュニティで質問・情報共有が可能
- APILayer連携 — IPstack・Weatherstack・Fixerなど商用サービスAPIも紹介
- 無料・オープンソース — MITライセンスで誰でも自由に活用可能
