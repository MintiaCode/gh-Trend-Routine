## 概要

Agent Toolkit for AWSは、AWSが公式にサポートするAIコーディングエージェント向けのMCPサーバー、スキル、プラグインのコレクションである。Claude Code、Codex、Cursor、Kiroといった主要なAIコーディングエージェントと統合し、AWS上でのアプリケーション構築・デプロイ・管理を支援する。コアプラグインはサービス選定、CDK/CloudFormation、サーバーレス、コンテナ、ストレージ、オブザーバビリティ、課金、SDK利用、デプロイメントをカバーする。さらにAmazon Bedrock/AgentCoreを活用したAIエージェント構築、S3 Tables/Glue/Athenaによるデータ分析・ETLワークフロー、DevSecOps向けのセキュリティスキャン・インシデント調査といった専門プラグインも提供している。AWS MCPサーバーを介してエージェントがAWSサービスに直接アクセスでき、ガードレール付きで安全に操作できる点が特徴だ。

---
## 主な機能・特徴

- AWS MCPサーバー — AIエージェントからAWSサービスへの安全なアクセスを提供するプロトコル層
- aws-coreプラグイン — サービス選定からデプロイまでAWS開発の基本スキルを網羅
- aws-agentsプラグイン — Amazon BedrockとAgentCoreを使ったAIエージェント構築支援
- aws-data-analyticsプラグイン — S3 Tables/Glue/AthenaによるデータレイクとETLワークフロー
- DevSecOpsプラグイン — インシデント調査・脆弱性スキャン・ペネトレーションテスト自動化
- マルチエージェント対応 — Claude Code/Codex/Cursor/Kiroとワンコマンドで統合
- スキルインストール — npx skills addで簡単にAWSスキルをエージェントに追加
- ガードレール内蔵 — エージェントの操作を安全な範囲に制限するセキュリティ機構
