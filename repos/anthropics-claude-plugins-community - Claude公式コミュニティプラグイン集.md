# anthropics/claude-plugins-community

▎ Claude公式コミュニティプラグイン集

ライセンス: Apache-2.0
言語: Python
スター数: ⭐ 862 (+257 今日)

---
## 概要

本リポジトリは、Claude CoworkおよびClaude Code向けのコミュニティ製プラグインを配布するための公式マーケットプレイスのミラーです。実体はAnthropic社内のレビューパイプラインから毎晩同期される`.claude-plugin/marketplace.json`という単一のカタログファイルであり、リポジトリ自体は読み取り専用です。ここに掲載されるプラグインはすべてclaude.aiの専用フォームから提出され、自動セキュリティスキャンを通過し、承認を受けたもののみが並びます。直接このリポジトリにプルリクエストを送ることはできず、変更はすべて内部レビューフローを経由します。Claude Coworkユーザーはclaude.com/pluginsから、Claude Codeユーザーは`claude plugin marketplace add`コマンドからこのマーケットプレイスを追加し、個々のプラグインをインストールできます。Anthropic公式が管理する`claude-plugins-official`や役割特化型の`knowledge-work-plugins`と並ぶ、コミュニティ主導のエコシステム拡張を支える基盤リポジトリです。

---
## 主な機能・特徴

- Claude Cowork/Claude Code向けコミュニティプラグインの公式カタログ
- `.claude-plugin/marketplace.json`をAnthropic内部レビューパイプラインから毎晩自動同期
- 掲載プラグインは自動セキュリティスキャンと審査を通過済み
- `claude plugin marketplace add`コマンドで簡単にマーケットプレイスを追加可能
- 直接のプルリクエストは自動クローズされ、提出は専用フォーム経由に一本化
- Apache-2.0ライセンスで公開
- 公式プラグイン集・知識労働向けプラグイン集など関連リポジトリと連携

## トレンド入り理由の推測

本日257件のスター増加という急増ぶりの主因は、Claude Cowork(Claude Codeの拡張版とみられる新製品)向けのプラグインエコシステムが公式にオープン化されたタイミングと重なっていることが大きいと考えられます。読み取り専用のミラーリポジトリという性質上、通常であれば注目を集めにくいはずですが、「コミュニティプラグインを公式にインストールできるようになった」という発表そのものが開発者コミュニティで大きな話題となり、一気に流入したスターだと推測されます。
