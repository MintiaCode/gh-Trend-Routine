## 概要

DS2APIは、DeepSeekのウェブ会話機能をOpenAI・Claude・Gemini互換APIとして変換する軽量・高性能なフルスタックミドルウェアです。バックエンドはGoで完全実装され、フロントエンドはReact製WebUI管理コンソールを提供します。マルチアカウントローテーション・コンパイル済みバイナリ・Vercel Serverless・Dockerなど多彩なデプロイオプションに対応します。クライアントSDKからはOpenAI・Claude・Gemini APIとして透過的に利用でき、DeepSeekのWebUI機能を無料APIとして活用することを目的としています。学習・研究・個人実験用途で設計されており、中国のLinux.doコミュニティを中心に開発されています。

---
## 主な機能・特徴

- マルチAPI互換 — OpenAI・Claude（Anthropic）・Gemini API形式を同時サポート
- マルチアカウントローテーション — 複数DeepSeekアカウントを順番に利用し負荷分散
- 多様なデプロイ方式 — Dockerワンコマンド・Vercel Serverless・Zeabur・バイナリ実行
- Go全量実装バックエンド — 軽量・高スループットなGo製サーバー
- React WebUI管理画面 — アカウント・設定をブラウザから管理できるコンソール
- ツールコール対応 — Function Calling（ツール呼び出し）のセマンティクスを適切に変換
- PoW実装 — Proof of WorkをピュアGoで実装してDeepSeek認証に対応
