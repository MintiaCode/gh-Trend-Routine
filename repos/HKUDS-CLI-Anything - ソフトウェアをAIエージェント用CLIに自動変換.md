# HKUDS/CLI-Anything

▎ ソフトウェアをAIエージェント用CLIに自動変換

ライセンス: Apache-2.0
言語: Python
スター数: ⭐ 35,500 (+306 今日)
トレンド順位: #2 (2026-05-17)

---
## 概要

CLI-Anythingは、あらゆるソフトウェアをAIエージェントから操作可能なコマンドラインインターフェースへと自動変換するPython製フレームワークです。7フェーズの自動パイプラインを通じて、ソースコードを解析し、標準化されたCLIハーネスを生成します。生成されたCLIはCADソフトウェア、3Dモデリングツール、動画編集ソフトなど18種類以上のアプリケーションで実証されており、2,269件以上のテストをパスしています。CLI-Hubと呼ばれるコミュニティプラットフォームでは、`pip install cli-anything-hub`でインストール後、即座にコミュニティ製CLIを利用できます。「今日のソフトウェアは人間のために、明日のユーザーはエージェントになる」というビジョンのもと、既存ソフトウェアとAIエージェントの橋渡しを担う実用的なツールです。研究成果を実装に落とし込んだ学術的背景を持つプロジェクトでもあります。

---
## 主な機能・特徴

- 7フェーズ自動パイプライン — ソースコード解析からCLIハーネス生成まで全自動化
- CLI-Hub — コミュニティ製CLIのブラウズ・インストール・管理プラットフォーム
- 2,269件以上のパステスト — 18種類の実際のアプリケーションで品質検証済み
- マルチソフトウェア対応 — CAD・3Dシーン・動画字幕など多様なアプリに対応
- コントリビューター参加型 — PRでCLIをHubに追加しコミュニティを拡充
- プレビュー・ライブプレビュー機能 — エージェントが生成する成果物をリアルタイム確認
- Apache-2.0ライセンス — 商用利用可能なオープンソースとして公開

## トレンド入り理由の推測

CLI-AnythingがトレンドとなったのはAIエージェントの普及が急速に進む中、「エージェントがどうやって既存ソフトウェアを操作するか」という根本的な課題に正面から取り組んでいるからです。2026年に入ってからClaude Code、OpenAI Codex、Gemini CLIなどのコーディングエージェントが実用域に達し、開発者コミュニティでは「次はどうやって任意のソフトウェアをエージェントから使えるようにするか」への関心が急高まりしています。

香港大学データサイエンス研究室（HKUDS）という学術機関発のプロジェクトであることも信頼性を高めています。論文ベースの研究を実装した体系的な7フェーズアプローチは、単なるハックではなく学術的な裏付けがある点で差別化されています。35,500スターという規模でありながら本日306スターを獲得したことは、AIコミュニティでの継続的な話題拡散を示しています。

v0.3.0のリリースやCLI-Hubの公開など、新たなコミュニティ参加の仕組みが整ったことで注目が再燃した可能性が高いです。エージェントネイティブなソフトウェアエコシステムの構築という大きなビジョンが業界トレンドと完全に合致しており、今後もスターが伸び続けると予想されます。
