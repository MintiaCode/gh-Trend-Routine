# maziyarpanahi/openmed

---
## 概要

OpenMedは、患者データをデバイス外に送信することなく、完全にオンデバイスで動作するローカルファーストの医療AIフレームワークである。臨床テキストから構造化された医療インサイトを抽出する機能を持ち、PythonとSwiftで実装されている。BERTやQwen、DeepSeekなどの軽量LLMをMLXフレームワーク上で実行し、iOS・macOS環境でのネイティブ動作を実現している。医療NER（固有表現認識）やPII（個人識別情報）検出機能を備え、患者のプライバシーを保護しながら高度な医療テキスト解析を行う。プライバシー規制が厳しい医療現場における「ソブリンAI（主権AI）」の実現を目指しており、病院や医療機関が外部クラウドに依存せずAIを活用できる環境を提供する。

---
## 主な機能・特徴

- 完全オンデバイス — 患者データが端末外に出ない完全ローカル動作
- 医療NER — 症状・薬剤・診断名などの医療固有表現を自動抽出
- PII検出 — 患者の個人識別情報を自動的に検出・保護
- MLX統合 — Apple Silicon最適化のMLXフレームワークで高速推論
- 複数LLM対応 — BERT、Qwen、DeepSeekなど複数モデルをサポート
- iOS/Swift対応 — SwiftUIによるiOSネイティブアプリとして動作
- Swift Package — Swift Package Managerによる容易な統合

## トレンド入り理由の推測

OpenMedが本日トレンド入りした背景には、医療現場でのAI活用における「プライバシー」と「コンプライアンス」への強い需要がある。GDPRやHIPAAなどの規制が医療データの扱いを厳しく制限する中、クラウドに患者情報を送信せずAIを活用できるソリューションは市場から強く求められている。v1.5.5が2026年6月8日（昨日）にリリースされたことが、本日のスター急増の直接的なトリガーと考えられる。

また、Apple Siliconの性能向上によりiOSデバイスでの医療グレードのLLM推論が現実的になった2026年という時期に、MLXを活用した実用的な医療AIフレームワークが登場したことは、開発者コミュニティに大きなインパクトを与えている。ソブリンAIという概念が欧州を中心に広まり、特に医療分野での「データ主権」への関心が高まっている背景もある。

PythonバックエンドとネイティブiOS UIを組み合わせたハイブリッドアーキテクチャ、そして完全OSSというアプローチが、医療系スタートアップや研究者に「使えるもの」として評価されているため、今後もスター増加が続くと予測される。
