# checkstyle/checkstyle

▎ Javaコード規約チェックツール

ライセンス: LGPL-2.1
言語: Java
スター数: ⭐ 9,172 (+124 今日)
トレンド順位: #10 (2026-08-30)

---
## 概要

CheckstyleはJavaのソースコードが定められたコーディング規約に沿っているかを自動でチェックする静的解析ツール。デフォルトでGoogle Java Style GuideやSun Code Conventionsに対応しており、XMLベースの設定ファイルで独自のルールセットを柔軟にカスタマイズできる。コマンドラインから単体で実行できるほか、AntタスクやMaven Centralへの公開により既存のビルドパイプラインにも組み込み可能で、違反箇所を詳細なレポートとして出力する。20年以上の歴史を持つJavaコミュニティの定番ツールであり、チーム開発におけるコードスタイルの統一やレビュー工数の削減を目的として、企業のJavaプロジェクトやOSSのCIパイプラインで広く使われている。

---
## 主な機能・特徴

- Google Java Style GuideやSun Code Conventionsを標準サポート
- XML設定ファイルによる柔軟なルールカスタマイズ
- コマンドライン単体実行とAnt/Maven連携の両方に対応
- 違反箇所を明示した詳細な解析レポートを出力
- 静的解析によりレビュー前にコードスタイル違反を検出
- Hacktoberfest対応でコントリビューションを歓迎
- LGPL-2.1/Apache-2.0のデュアルライセンス構成
- 長年の実績を持つJavaエコシステムの定番ツール

Checkstyleは総スター9,172に対し本日124個の増加と、老舗の静的解析ツールとしては珍しい伸びを見せている。目立った新機能リリースよりも、Java向けAIコーディングエージェントや自動レビューツールが急増する中で、そのバックエンドとしてCheckstyleのルールエンジンが再評価されている可能性が考えられる。
