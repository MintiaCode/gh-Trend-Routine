## 概要

Scientific Agent Skillsは、AIエージェントを強力な科学研究アシスタントへと変換する135種類のスキルを収録したオープンソースリポジトリです。Claude Code、Cursor、Codexなどのエージェントに対応し、バイオインフォマティクス、創薬、臨床研究、材料科学、ゲノミクスなど幅広い科学分野のワークフローを自動化します。PubChem、ChEMBL、UniProt、ClinicalTrials.govなど100以上の専門データベースと統合されており、複雑な研究パイプラインを単一プロンプトで実行できます。npmやGitHub CLIで簡単にインストールでき、研究者やデータサイエンティストが環境構築やAPIドキュメント調査に費やす時間を大幅に削減できる実践的なツールキットです。

---
## 主な機能・特徴

- 135の専門スキル — バイオインフォマティクス、創薬、臨床研究、機械学習など多分野をカバー
- 100以上のデータベース統合 — PubChem、ChEMBL、UniProt、ClinicalTrials.govなど専門DBに対応
- 70以上のPythonパッケージスキル — RDKit、Scanpy、PyTorch Lightning、scikit-learnに最適化
- 複数エージェント対応 — Claude Code、Cursor、Codexなど主要AIコーディングエージェントで動作
- ワンコマンドインストール — `npx skills add`コマンドで即座に導入可能
- 自動スキル発見 — エージェントがタスクに最適なスキルを自動的に選択・適用
- 包括的ドキュメント — 各スキルにコード例・ベストプラクティスが付属
