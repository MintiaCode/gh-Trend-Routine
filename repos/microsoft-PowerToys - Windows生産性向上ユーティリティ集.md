## 概要

Microsoft PowerToysは、Windowsのカスタマイズと日常作業の効率化を支援する30以上のユーティリティのコレクションです。Microsoftが開発・公開するオープンソースプロジェクトとして、Windows 10・11に対応しています。FancyZones（ウィンドウレイアウト管理）・Color Picker・Command Palette・Keyboard Manager・PowerRename・Image Resizer・Advanced Pasteなど多様なツールを一つのパッケージで提供します。C#で実装されており、MITライセンスでソースコードが公開されているため、コミュニティからの機能追加・バグ修正のコントリビューションも積極的に受け付けています。Windows 11の機能を補完・拡張する存在として、開発者・パワーユーザー双方に広く使われています。

---
## 主な機能・特徴

- FancyZones — カスタムウィンドウレイアウトを定義してウィンドウを効率的に配置
- Command Palette — キーボードからアプリ・設定・ファイルに素早くアクセス
- Advanced Paste — クリップボード履歴管理とAI支援テキスト変換機能
- Color Picker — 画面上の任意のカラーコードをピックアップしてコピー
- PowerRename — 正規表現を使った一括ファイルリネーム
- Image Resizer — エクスプローラーの右クリックから画像を一括リサイズ
- Keyboard Manager — キーバインドの再マッピングとカスタムショートカット作成
