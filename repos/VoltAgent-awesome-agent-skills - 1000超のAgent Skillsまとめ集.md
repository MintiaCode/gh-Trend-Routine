## 概要

本リポジトリは、Anthropic、Google Labs、Vercel、Stripe、Cloudflare、Netlify、Sentry、Hugging Face、Figmaなど、第一線の開発チームおよびコミュニティが公開している「Agent Skills(エージェント向けスキル)」を1000件以上まとめたキュレーションリストです。大量生成されたAI製の粗悪なコンテンツを排除し、実際のエンジニアリングチームが実務で使っているスキルのみを厳選して収録している点が特徴です。Claude Code、Codex、Antigravity、Gemini CLI、Cursor、GitHub Copilot、OpenCode、Windsurfなど、主要なAIコーディングエージェントとの互換性を明示し、各スキルへのパスとドキュメントを一覧できる目次を提供しています。バックエンド開発、テスト、DevOps、セキュリティ、コンテンツ管理、クラウド、マーケティングなど多様な領域をカバーしており、AIエージェントの能力を特定タスクに特化させたい開発者やチームにとって、信頼できるスキルのカタログとして機能します。VoltAgentコミュニティが継続的に更新・メンテナンスを行っている、現時点で最も多くの貢献を集めているAgent Skillsリポジトリの一つです。

---
## 主な機能・特徴

- 1000件超のAgent Skillsを収録 — 公式チーム発とコミュニティ発を明確に区別
- Anthropic、Vercel、Stripe、Cloudflareなど有力企業の公式スキルを掲載
- Claude Code、Codex、Cursor、Gemini CLIなど主要エージェントとの互換性を明記
- カテゴリ別の充実した目次 — 開発チーム別・用途別に素早く検索可能
- 「AIスラップ」排除の品質基準 — 実務利用実績のあるスキルのみ厳選
- Awesomeリスト公式認定(awesome.re)バッジを取得
- コミュニティによる継続的な更新とスポンサー制度

## トレンド入り理由の推測

本日約223件のスター増加でトレンド入りした背景には、Claude Code の「Skills」機能をはじめとするAIコーディングエージェントのスキル/プラグイン化トレンドが急速に広がっていることが挙げられます。総スター数3万件超という規模はすでに「Awesome」リストの中でも確立した地位を示していますが、有力企業が続々と公式スキルを公開する動きに合わせて継続的に新しいスターを集めています。

技術的には、単一のツールに閉じず、Claude Code、Codex、Gemini CLI、Cursorなど複数のエージェントプラットフォームに対応している点が、特定ベンダーにロックインされたくない開発者から支持を得ている理由と考えられます。また「AI製の粗悪なスキルを排除する」という明確な品質方針が、玉石混交になりがちなAwesomeリスト分野での差別化要因になっています。

さらに、エージェントスキルという概念自体が2026年に入り急速に一般化しており、社内ナレッジや業務手順をAIエージェントに渡す標準的な手段として定着しつつあることも、継続的なスター獲得の追い風になっています。
