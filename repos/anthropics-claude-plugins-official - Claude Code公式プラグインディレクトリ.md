## 概要

Anthropic公式が管理するClaude Codeプラグインのキュレーションディレクトリ。高品質なプラグインをAnthropicチームが直接管理する内部プラグインと、サードパーティのパートナーやコミュニティ開発者が作成した外部プラグインの2種類を収録している。インストールは `/plugin install {plugin-name}@claude-plugins-official` コマンドで行え、プラグインの探索・導入を簡単に実行できる。外部プラグインは品質・セキュリティ基準を満たした場合のみ承認されるため、信頼性が高い。開発者は専用フォームからプラグイン登録を申請でき、MCPサーバー設定・スラッシュコマンド・スキル定義などの標準フォーマットに沿って実装する必要がある。

---
## 主な機能・特徴

- 内部プラグイン — Anthropic直接管理の公式参照実装プラグイン群
- 外部プラグイン — サードパーティ開発の審査・承認済みプラグイン群
- 簡単インストール — `/plugin install` コマンド一発で導入可能
- プラグイン探索機能 — Claude Code内のディスカバリーUI付き
- 標準フォーマット — MCP設定・スラッシュコマンド・スキル定義を含む統一構造
- 品質審査 — 外部プラグインはセキュリティ・品質基準をパスしたもののみ掲載
- 開発者向け申請 — 専用フォームからコミュニティ貢献可能
