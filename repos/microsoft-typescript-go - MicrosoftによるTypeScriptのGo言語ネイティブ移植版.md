# microsoft/typescript-go

▎ MicrosoftによるTypeScriptのGo言語ネイティブ移植版

ライセンス: Apache-2.0
言語: Go
スター数: ⭐ 25175 (+23 今日)

---
## 概要

MicrosoftがTypeScriptコンパイラをGo言語でネイティブ実装した実験的リポジトリです。TypeScript 7として提供予定で、npmの`@typescript/native-preview`パッケージとして現在試用することができます。`npx tsgo`コマンドで従来の`tsc`と同様に使用でき、VS Code拡張機能も用意されています。現在はプログラム作成・パース・型解決・型チェック・JSXサポート・JavaScriptエミット・インクリメンタルビルドなどが動作しており、宣言エミットやウォッチモードは開発中の段階です。長期的にはこのリポジトリの内容がmicrosoft/TypeScriptに統合される予定であり、TypeScriptエコシステム全体の性能を根本から向上させることを目指しています。

---
## 主な機能・特徴

- Go言語によるネイティブ実装 — パフォーマンスを大幅に向上させるコンパイラの言語レベル移植
- TypeScript 7対応 — npm `@typescript/native-preview`としてプレビュー公開中
- `npx tsgo`コマンド — 従来の`tsc`と同様のCLIインターフェースで即座に利用可能
- VS Code拡張機能 — マーケットプレイスから対応拡張機能をインストール可能
- 型チェック・JSX・インクリメンタルビルド — 主要機能はすでに実装済み
- 長期的にmicrosoft/TypeScriptへ統合予定 — 公式TypeScriptの高速化が最終目標

## トレンド入り理由の推測

microsoft/typescript-goは今日の増加スター数が23と比較的少ないにもかかわらずトレンド入りしており、他の急騰リポジトリと比べると落ち着いた動きです。それでもトレンドに登場した理由は、TypeScriptのGo言語移植という話題性の高いプロジェクトとして継続的にデベロッパーコミュニティの注目を維持しているためです。

Go言語の高速なコンパイル速度でTypeScriptの型チェックを実現するという目標は、大規模TypeScriptプロジェクトを抱える企業にとって非常に魅力的です。特にMonorepoや大規模プロジェクトではtscの速度がボトルネックになることが多く、この問題を根本から解決するアプローチとして継続的な関心が寄せられています。

TypeScript 7のプレビューが`@typescript/native-preview`として試用可能になったことで、実際に使ったエンジニアによるレビューやブログ記事が継続的に公開されており、それが定期的なトラフィック流入につながっていると推測されます。
