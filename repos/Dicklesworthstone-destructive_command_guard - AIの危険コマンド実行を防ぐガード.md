## 概要

dcg (Destructive Command Guard) は、AIコーディングエージェントが `git reset --hard` や `rm -rf`、`DROP TABLE` のような破壊的なシェルコマンドを誤って実行してしまう問題に対処するツールです。Claude Code や Codex CLI、Gemini CLI、GitHub Copilot CLI、Cursor など主要なAIエージェントのフック機構に組み込まれ、コマンド実行前にリアルタイムで危険性を評価します。内部では4段階のパイプライン(JSON解析→正規化→SIMDによる高速な事前フィルタリング→パターンマッチング)を採用し、50以上のセキュリティパックに含まれる数千の破壊的パターンと照合しつつ、サブミリ秒の低遅延を実現しています。文脈を理解する解析により、「grep 'rm -rf'」のようなデータとしての文字列と、実際に実行されるコマンドを区別できる点が特徴です。対象ユーザーは、AIエージェントを日常的に使う開発者や、CI/CDパイプラインに監査可能なコマンド検証を組み込みたいチーム、セキュリティポリシーを強化したい組織です。フェイルオープン設計により、タイムアウトや解析エラー時には作業を止めずに継続できる柔軟性も備えています。

---
## 主な機能・特徴

- リアルタイムフック — Claude Code や Copilot CLI など主要AIエージェントに標準フックで統合
- 4段階パイプライン — JSON解析・正規化・SIMD高速フィルタ・パターンマッチングで高速判定
- 50以上のセキュリティパック — DB、Kubernetes、クラウド、CI/CD、DNSなど幅広くカバー
- 文脈認識 — コメントやクォート文字列と実行コマンドを正確に区別
- ヒアドキュメント解析 — Python/BashのインラインスクリプトをAST解析で検査
- dcg test / explain / scan — 事前評価・判定トレース表示・CI向けスキャン機能
- 多層設定システム — 環境変数からプロジェクト/ユーザー設定まで柔軟にカスタマイズ可能
- クロスプラットフォーム対応 — Linux, macOS, Windows(WSL/PowerShell)をサポート
