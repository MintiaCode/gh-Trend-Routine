## 概要

open-code-reviewは、Alibaba Group社内で実運用されてきたコードレビューシステムをオープンソース化したCLIツールです。Gitの差分を読み取り、設定可能なLLM(OpenAI・Anthropic互換)にツール利用機能を持たせて解析させることで、行単位の精度で構造化されたレビューコメントを自動生成します。

決定論的なパイプライン(正確なファイル選定、スマートなバンドリング、ルールマッチング)とLLMエージェントによる動的な判断・コンテキスト取得を組み合わせたハイブリッドアーキテクチャが最大の特徴です。NPE、スレッドセーフティ、XSS、SQLインジェクションなど、あらかじめチューニングされたルールセットを内蔵しており、汎用エージェントよりも高精度かつ低コストなレビューを実現しています。

50のOSSリポジトリと200件のプルリクエストを用いた検証では、同一モデルを使用した場合に汎用エージェント比で高いPrecision・F1スコアを達成しつつ、トークン消費は約1/9に抑えられたと報告されています。対象ユーザーは、CI/CDにコードレビューを組み込みたい開発チームや、Claude Code・Codex・Cursorなど既存のエージェント環境と連携させたい企業です。npmから`npm install -g`で簡単に導入でき、ワークスペースモード・ブランチ比較・単一コミット・全ファイルスキャンなど複数のレビューモードを備えています。

---
## 主な機能・特徴

- ハイブリッドアーキテクチャ — 決定論的パイプラインとLLMエージェントの組み合わせ
- 行単位の高精度コメント — 一般的なエージェントより精密なレビュー
- 内蔵ルールセット — NPE・スレッドセーフティ・XSS・SQLインジェクション等を検出
- 低トークンコスト — 汎用エージェント比で約1/9のトークン消費
- マルチプラットフォーム対応 — Windows・macOS・Linuxで動作
- 既存エージェント連携 — Claude Code・Codex・Cursorと互換
- 複数レビューモード — ワークスペース・ブランチ比較・コミット単位・全ファイルスキャン
- Alibaba発の実績 — 社内での実運用実績に基づく設計
