# pbakaus/impeccable

▎ AIハーネス向けフロントエンドデザインスキル

ライセンス: Apache-2.0
言語: JavaScript
スター数: ⭐ 32600 (+612 今日)

---
## 概要

Impeccableは、AIコーディングアシスタント（Claude Code、Cursor、Gemini CLIなど）がフロントエンドデザインをより高品質に生成するための包括的なデザインスキルです。AI生成コードが陥りがちなデザインの落とし穴を解決することを目的として設計されており、元々はAnthropicのフロントエンドデザインスキルから派生しています。7つのドメイン参照ファイル（タイポグラフィ、カラー、スペーシング、モーション、インタラクション、レスポンシブデザイン、UXライティング）と23のコマンドを提供し、27種類の決定的なアンチパターン検出と12のLLMベースの批評ルールを組み合わせることでAIが生成するUIの品質を大幅に向上させます。Cursor、Claude Code、VS Code Copilotなど11以上のAI開発ツールと互換性があり、フロントエンド開発者やAIアシスタントを活用するチーム全般を対象としています。

---
## 主な機能・特徴

- 7つのデザインドメイン参照ファイル — タイポグラフィ、カラー、スペーシング、モーション、インタラクションなどをカバー
- 23のスラッシュコマンド — `/impeccable audit`や`/impeccable polish`など実用的なコマンドを提供
- 27種類のアンチパターン検出 — AI生成UIに現れがちな典型的デザイン欠陥を自動検出
- 12のLLMベース批評ルール — より高度で主観的なデザイン評価を実施
- 11以上のAIツール対応 — Cursor、Claude Code、Gemini CLI、OpenCodeなどに対応
- スタンドアロンCLI — `npx impeccable skills install`でインストール、AIハーネスなしでもスキャン可能
- Apache 2.0ライセンス — オープンソースで自由に利用・改変・再配布が可能
