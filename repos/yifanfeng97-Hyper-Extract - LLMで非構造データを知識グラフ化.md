# yifanfeng97/Hyper-Extract

▎ LLMで非構造データを知識グラフ化

ライセンス: Apache-2.0
言語: Python
スター数: ⭐ 1700 (+124 今日)
トレンド順位: #7 (2026-06-18)

---
## 概要

Hyper-Extractは、LLMを活用して非構造化テキストを構造化された知識に変換するCLIフレームワークです。単純なリストやPydanticモデルから、ナレッジグラフ、ハイパーグラフ、さらには時空間グラフまで、8種類の知識構造への抽出を1コマンドで実行できます。GraphRAG、LightRAG、Hyper-RAGなど10以上の抽出エンジンを内蔵し、金融・法律・医療・漢方医学・産業など80以上のYAMLテンプレートがノーコードで利用可能です。インクリメンタル進化機能により、新しい文書を追加するたびに知識ベースを拡張・精緻化でき、vLLMによるローカルデプロイメントにも対応しているため、機密データをオンプレミスで安全に処理できます。研究者、金融アナリスト、データサイエンティストなど、大量の非構造化文書から体系的な知識を抽出したいユーザーに最適なツールです。

---
## 主な機能・特徴

- 8種類の知識構造 — リスト、セット、Pydanticモデル、ナレッジグラフ、ハイパーグラフ、時空間グラフまで対応
- 10以上の抽出エンジン — GraphRAG、LightRAG、Hyper-RAG、KG-Genなどをすぐに利用可能
- 80以上のYAMLテンプレート — 金融・法律・医療など多分野でノーコード抽出
- インクリメンタル進化 — 新文書追加で既存の知識ベースを継続的に拡張・改善
- ローカルデプロイメント — vLLMでQwen3.5-9Bなどを使いデータを外部に出さず処理
- 対話型検索 — 構築した知識ベースに対して自然言語で質問可能
- 可視化機能 — 抽出した知識構造をインタラクティブに表示
- マルチプラットフォームLLM対応 — OpenAI、阿里云百炼、ローカルvLLMなど多数のモデルをサポート

## トレンド入り理由の推測

RAG（Retrieval-Augmented Generation）とナレッジグラフの組み合わせは2026年のAI開発で最もホットなトピックの一つであり、Hyper-Extractはこの需要に直接応えるツールです。GraphRAGやLightRAGなどの既存手法を統一的なCLIインターフェースで利用できる点は、個別のフレームワークを組み合わせる手間を大幅に省き、多くの開発者・研究者にとって即座に価値を提供します。

特に注目すべきは「ハイパーグラフ」への対応です。従来のナレッジグラフが2者間関係のみを表現するのに対し、ハイパーグラフは多者間の複雑な関係を一つのハイパーエッジで表現できます。これは学術研究や複雑な業務分析において重要な差別化要素であり、既存ツールでは容易に実現できない機能です。80以上のドメイン特化テンプレートにより、プログラミング知識がなくても専門分野での知識抽出が可能な点も、幅広いユーザー層への訴求力を持っています。

v0.2.0の最近のリリースとuvによる簡単なインストール（`uv tool install hyperextract`）も普及を後押ししており、AIエージェントのメモリやRAGパイプラインの構築を検討している開発者層からの関心が集中していると推測されます。
