# millionco/react-doctor

## 概要

React Doctorは、AIエージェントが生成したReactコードの品質問題を自動検出するTypeScript製の静的解析ツールです。0〜100のヘルススコアとともに、状態管理・副作用・パフォーマンス・アーキテクチャ・セキュリティ・アクセシビリティ・デッドコードの7カテゴリで問題点を診断します。`npx -y react-doctor@latest .`のワンコマンドで即座にスキャンが開始でき、Claude Code・Cursor・Codex・OpenCodeなど50以上のAIコーディングエージェントとの統合に対応しています。GitHub Actionとして組み込むことでCIパイプライン内にPRコメントとしてスコアを出力することも可能です。Next.js・Vite・React Nativeをサポートし、既存の.eslintrcや.oxlintrcも尊重します。AIエージェントの普及でReactのアンチパターンが急増している現代において、コードベースの健全性を維持するためのパターン検出ツールです。

---
## 主な機能・特徴

- ヘルススコア算出 — 0〜100のスコアで7カテゴリのコード品質を一覧診断
- AIエージェント対応 — Claude Code・Cursor・Codex等50以上のエージェントと連携
- ワンコマンドスキャン — npx一行で即座にプロジェクト全体を解析
- GitHub Actions統合 — CIパイプラインでPRコメント・スコア出力に対応
- マルチフレームワーク対応 — Next.js・Vite・React Nativeをサポート
- 設定ファイル互換 — 既存の.eslintrcや.oxlintrcを尊重した柔軟なルール管理
- 段階的スコア評価 — 75+(優良)・50-74(要改善)・50未満(危機的)の3段階判定
