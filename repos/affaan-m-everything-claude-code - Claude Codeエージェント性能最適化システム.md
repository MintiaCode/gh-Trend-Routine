## 概要

Everything Claude Codeは、AIエージェントハーネスの性能最適化システムです。Anthropicハッカソン優勝作品として生まれ、10ヶ月以上の実際のプロダクト開発での日常使用から進化したプロダクション対応の設定・スキル・ルール集です。単なる設定ファイル集ではなく、スキル（技能定義）・本能（instinct/自動行動）・メモリ最適化・継続的学習・セキュリティスキャン・リサーチファースト開発の完全システムを提供します。Claude Code・Codex・Cursor・OpenCode・Geminiなど複数のAIエージェントハーネスに対応し、12以上の言語エコシステムをサポート。トークン最適化・メモリ永続化・検証ループ・並列化・サブエージェントオーケストレーションなど、エージェント開発の実践的課題を体系的に解決します。177,932スターと27,000以上のフォークを持つ超人気リポジトリで、170以上のコントリビューターが継続参加しています。

---
## 主な機能・特徴

- スキル＆本能システム — エージェントが自動的に実行する再利用可能な技能定義と行動パターンを提供
- トークン最適化 — モデル選択・システムプロンプト圧縮・バックグラウンドプロセスでAPI費用を削減
- メモリ永続化フック — セッション間でコンテキストを自動保存・復元するhooksシステム
- AgentShieldセキュリティ — プロンプトインジェクション・攻撃ベクトルに対するエージェントセキュリティスキャン
- 並列化サポート — Gitワークツリー・カスケードメソッドでエージェントインスタンスをスケール
- MCP設定集 — Model Context Protocolの実践的設定テンプレートを完備
- クロスハーネス対応 — Claude Code/Codex/Cursor/OpenCode/Geminiを統一アーキテクチャで管理
