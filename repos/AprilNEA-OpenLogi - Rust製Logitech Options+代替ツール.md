## 概要

OpenLogi は、Logitech 純正の設定アプリ「Logi Options+」を置き換えることを目的とした、Rust 製のネイティブかつローカルファーストなデバイス管理ツールである。マウス・キーボード・ウェブカメラといった Logitech 製周辺機器を、アカウント登録もテレメトリ送信もなしに制御できる。

純正アプリは長らく、常駐時のメモリ消費の大きさ、アカウントログインの強制、クラウド同期を前提とした設計、そして起動の遅さで不満を集めてきた。単にマウスのボタンを割り当て直したいだけのユーザーにとって、これらは過剰な代償である。OpenLogi は HID++ プロトコルと UVC を直接叩くことでこの中間層を取り払い、設定は TOML の平文ファイルとして手元に置く。結果として、設定ファイルを dotfiles と一緒に Git で管理し、複数マシン間でそのまま同期できる。

機能面では純正を単に模倣するのではなく踏み込んでおり、任意のボタンへのジェスチャー割り当て、DPI プリセットと巡回切り替え、SmartShift ホイールの調整、デバイスごとのスクロール反転、Actions Ring オーバーレイ、F キーのグローバル再割り当て、対応機種の RGB 制御、UVC ウェブカメラのライブプレビュー付き画質調整までを備える。アプリケーションごとのプロファイル自動切り替えにも対応し、GUI に加えて CLI も提供される。macOS・Linux・Windows すべてに配布パッケージが用意され、NixOS 向けの flake モジュールまで同梱されている点に、対象ユーザー層がよく表れている。

## 主な機能・特徴

- HID++ 直接制御 — Logi Bolt・Unifying・Bluetooth・有線のいずれの接続でもデバイスを操作
- ボタン再割り当て — 任意の対応ボタンへアクションとジェスチャーを自由に紐付け
- DPI 管理 — プリセット登録とワンボタンでの巡回切り替えに対応
- SmartShift 調整 — ホイールのラチェット/フリースピン挙動を細かくチューニング
- TOML 設定ファイル — 平文管理でマシン間同期と dotfiles へのバージョン管理が可能
- アプリ別プロファイル — 前面アプリに応じた設定オーバーレイを自動適用
- UVC カメラ制御 — ズーム・フォーカス・露出・明るさをライブプレビューを見ながら調整
- クロスプラットフォーム配布 — DMG / DEB / RPM / Pacman / MSI に加え NixOS flake を提供
