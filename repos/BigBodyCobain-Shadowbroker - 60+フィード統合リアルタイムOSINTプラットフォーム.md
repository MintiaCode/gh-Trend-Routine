# BigBodyCobain/Shadowbroker

言語: Python
スター数: ⭐ 7,000 (+405 今日)

## 概要

Shadowbrokerは、航空機・船舶・衛星・地震・森林火災・監視カメラ・紛争地帯など60以上のリアルタイム公開フィードを統一マップインターフェースに集約するOSINT（公開情報収集）プラットフォームです。Next.js・MapLibre GL・FastAPI・Pythonで構築され、35以上のトグル可能なデータレイヤーを提供します。デフォルト・衛星・サーマル・ナイトビジョン・レトロターミナルなど複数のビジュアルモードを持ち、公開データソースのみを使用するため新たな監視手段を追加するものではないとしています。OpenSky Network（航空）・AISストリーム（海事）・CelesTrak（衛星）・USGS（地震）・NASA FIRMS（火災検知）などが統合されており、グローバルな情報を一画面で把握できます。AGPL-3.0ライセンスで公開された分散型インテリジェンスツールです。

---
## 主な機能・特徴

- 60+公開フィード統合 — 航空・海事・衛星・環境・監視カメラをワンマップに集約
- 35+データレイヤー — SAR地表変化検知を含むトグル可能な情報レイヤー
- マルチビジュアルモード — 衛星・サーマル・ナイトビジョン・レトロターミナル表示
- リアルタイム追跡 — プライベートジェット・スパイ衛星・地震イベントをライブ監視
- 分散型インテリジェンスメッシュ — 実験的なP2Pメッセージング機能（テストネット）
- ユーザーデータ非収集 — 既存の公開データセットのみ使用
- Python + Next.js構成 — バックエンドFastAPI・フロントエンドMapLibre GL

## トレンド入り理由の推測

Shadowbrokerが本日405スターを急増させたのは、地政学的緊張が高まる時代において「誰でも使える公開情報監視ツール」への関心が急激に高まっているからです。プライベートジェット追跡（"elonjet"トピックが示す通り）や衛星動向監視といった機能は、一般市民やジャーナリスト、研究者が政府・企業の動きを独自に追跡できる手段として注目されています。

技術的には、60以上の公開フィードを単一の洗練されたUIで提供するという実装の完成度が高く、OSINTコミュニティのパワーユーザーが発見して拡散した可能性があります。v0.9.79という頻繁なアップデート履歴も、活発な開発を示しています。

また「Shadowbroker」という名前自体がNSAのハッキングツールリークで有名な集団を想起させるブランディング効果を持ちます。AIと地政学的監視への関心が交差するニッチで、SNS上のOSINT・セキュリティリサーチコミュニティでバイラル拡散した可能性が高いと推測されます。
