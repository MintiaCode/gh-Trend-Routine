# Lakr233/vphone-cli

▎ 仮想iPhoneをMacで起動するツール

ライセンス: MIT
言語: Swift
スター数: ⭐ 9,537 (+341 今日)
トレンド順位: #3 (2026-08-30)

---
## 概要

vphone-cliはApple SiliconのMacでAppleの仮想化フレームワーク(Virtualization.framework)を用いて仮想iPhoneを起動するCLIツール。Private Cloud Compute(PCC)のリサーチVM基盤を応用し、ファームウェアのダウンロードからパッチ適用、DFUリストア、カスタムファームウェア(CFW)インストール、初回起動までを1コマンドでエンドツーエンドに自動化する。セキュリティ制限の緩さが異なる5種類のファームウェアバリアントを提供し、最小限のパッチ適用から完全な脱獄構成まで選択可能。SSH/VNCによるゲストへの接続や、AI駆動のE2Eテストを想定したホスト制御ソケットも備え、VMのクローン・エクスポート・インポートといった管理機能も揃う。iOS内部のセキュリティ研究者やリバースエンジニア、CI環境でのiOSアプリ自動テストを行いたい開発者を主な対象とする。

---
## 主な機能・特徴

- ワンコマンドVM構築 — ダウンロード→パッチ→DFUリストア→CFWインストール→初回起動を自動化
- 5種類のファームウェアバリアント — 最小パッチから研究向けフル脱獄構成まで選択可能
- SSH/VNC接続 — ゲストの仮想iPhoneに直接アクセス可能
- ホスト制御ソケット — AI駆動のE2Eテストなどプログラムからの自動操作に対応
- VM管理機能 — クローン・エクスポート・インポート・設定変更をサポート
- Apple Silicon + macOS 15以降が必須、SIP/AMFIの緩和設定が必要
- MITライセンスのオープンソース

## トレンド入り理由の推測

vphone-cliは総スター9,537に対し本日341個を獲得しており、iOSセキュリティ・リバースエンジニアリング界隈というニッチな分野としては急激な伸びである。Apple Silicon Mac上でPCC(Private Cloud Compute)のリサーチVM基盤を流用し仮想iPhoneを手軽に起動できるという着眼点が新規性が高く、通常は高いハードルを伴うiOS内部解析・脱獄環境構築を1コマンドまで簡略化した点がSNSやセキュリティコミュニティで話題になったとみられる。
