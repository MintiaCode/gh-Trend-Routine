## 概要

PakeはRust製フレームワークTauriを基盤とした、Webページをデスクトップアプリケーションに変換するCLIツールである。Electronベースのソリューションと比較して約20分の1のパッケージサイズを実現し、メモリ消費量も大幅に抑えている。コマンド一発で任意のURLをmacOS・Windows・Linux対応のネイティブアプリにパッケージングでき、開発知識がなくてもGitHub Actionsを使ったオンラインビルドも可能。ChatGPT、Gemini、Claude、YouTube、DeepSeekなど人気Webサービスの既製パッケージも提供されており、すぐにデスクトップアプリとして利用できる。ショートカットキー、イマーシブウィンドウ、ドラッグ＆ドロップ、スタイルカスタマイズ、広告除去などの機能も搭載し、Webアプリの利便性をネイティブアプリの体験に昇華させるツールとして、フロントエンド開発者から一般ユーザーまで幅広い層に支持されている。

---
## 主な機能・特徴

- ワンコマンドパッケージング — URLを指定するだけでデスクトップアプリを生成
- 超軽量 — Electronの約20分の1のサイズ、約5MB程度のアプリを出力
- クロスプラットフォーム — macOS・Windows・Linuxの全環境に対応
- 既製パッケージ配布 — ChatGPT・YouTube・DeepSeekなど人気サービスの即利用アプリ
- GitHub Actionsビルド — 開発環境不要のオンラインビルド機能
- カスタマイズ機能 — アイコン・ウィンドウサイズ・タイトルバー非表示など詳細設定可能
- ショートカットキー — ズーム・ナビゲーション・デバッグなど豊富なキーバインド
- 広告除去・スタイル変更 — CSSインジェクションによる表示カスタマイズ
