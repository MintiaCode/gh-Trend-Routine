## 概要

Next.jsはVercelが開発するReactベースのフルスタックWebフレームワークで、サーバーサイドレンダリング(SSR)、静的サイト生成(SSG)、インクリメンタル静的再生成(ISR)、そしてApp Routerによるサーバーコンポーネントなど、モダンなWeb開発に必要な機能を統合的に提供する。素のReactだけではルーティング、データフェッチ、ビルド最適化、画像・フォント最適化などを自前で組み合わせる必要があり、構成や性能チューニングの負担が大きいという課題があった。Next.jsはこれらをフレームワークとして標準化し、ファイルベースのルーティングやRust製ツールチェーン(SWC、Turbopack)による高速ビルドを実現することで、開発者が本質的なアプリケーションロジックに集中できるようにしている。対象ユーザーは個人開発者から大企業まで幅広く、Vercelをはじめ世界中の大規模サービスで採用されており、マーケティングサイトからECサイト、大規模SaaSまで様々な用途の本番環境で利用されている。

---
## 主な機能・特徴

- App Router — Reactサーバーコンポーネントを用いたレイアウト・ルーティングの新方式
- ハイブリッドレンダリング — SSR・SSG・ISR・CSRを1つのアプリ内で自由に組み合わせ可能
- Turbopack — Rust製の高速バンドラーによる開発サーバーの高速化とビルド時間短縮
- 画像・フォント最適化 — next/imageやnext/fontによる自動最適化とレイアウトシフト防止
- ファイルベースルーティング — pagesやappディレクトリの構造がそのままURL構造になる
- API Routes — フロントエンドと同一プロジェクト内でサーバーサイドAPIを構築可能
- ミドルウェア — リクエスト単位でのリダイレクトや認証処理をエッジで実行
- ゼロコンフィグ — 複雑な設定なしにTypeScript・ESLint等を標準サポート
