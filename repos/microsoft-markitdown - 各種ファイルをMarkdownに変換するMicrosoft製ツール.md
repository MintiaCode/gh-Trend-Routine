## 概要

MarkItDownは、Microsoftが開発したPython製のファイル変換ツールで、PDF・Word・Excel・PowerPoint・画像・音声などあらゆる形式のファイルをMarkdown形式に変換します。LLM（大規模言語モデル）との連携を主な用途として設計されており、ドキュメント構造（見出し・リスト・テーブル・リンク等）を保持しながらLLMが扱いやすい形式での出力を実現します。Python 3.10以上が必要で、`pip install 'markitdown[all]'`でフルインストール可能。コマンドラインツールとしても利用でき、AutoGen・LangChainなどのAIフレームワークとの連携も容易です。Azureのドキュメントインテリジェンスサービスとの統合により高品質な変換も実現し、OCRプラグインによる画像内テキスト抽出やYouTube URL対応など拡張性の高いアーキテクチャを採用しています。

---
## 主な機能・特徴

- 幅広いフォーマット対応 — PDF・Word・Excel・PowerPoint・HTML・画像・音声・ZIP・EPUBに対応
- LLM最適化出力 — LLMが扱いやすいMarkdown形式での出力とドキュメント構造の保持
- コマンドライン対応 — `markitdown file.pdf > output.md`のシンプルなCLI操作が可能
- プラグインアーキテクチャ — OCRプラグイン等のサードパーティ拡張をサポート
- Azure連携 — Azure Document Intelligenceによる高品質な構造化変換
- 選択的インストール — 必要な形式のみの依存関係インストールで軽量化が可能
- YouTube URL対応 — YouTubeのコンテンツも変換対象としてサポート
