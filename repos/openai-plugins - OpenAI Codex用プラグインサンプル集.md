## 概要

openai/pluginsはOpenAI Codexエージェント向けのプラグインサンプルを集めたキュレーションリポジトリです。各プラグインは`plugins/<name>/.codex-plugin/plugin.json`のマニフェスト形式で構成され、スキル・エージェント・コマンド・MCPファイル・フックなどの要素を組み合わせて機能します。Figma・Notion・Expo・Netlify・Google Slidesなど多様なツール向けの実践的なプラグイン例が含まれ、iOS/macOS/Webアプリ開発ワークフローをCodexエージェントで自動化するユースケースを網羅しています。CodexのプラグインシステムをゼロN理解したい開発者にとって、公式リファレンスとして活用できる貴重なリポジトリです。

---
## 主な機能・特徴

- プラグインマニフェスト仕様 — `.codex-plugin/plugin.json`による標準化された定義形式
- Figmaプラグイン — Code to Canvas・Code Connect・デザインシステムルール対応
- Notionプラグイン — 計画・リサーチ・ミーティング・知識管理ワークフロー
- iOS/macOSアプリ開発プラグイン — SwiftUI実装・パフォーマンス・デバッグ支援
- Expoプラグイン — React Native・EASワークフロー・SDK升级対応
- Webアプリプラグイン — デプロイ・UI・決済・DB連携ワークフロー
- MCP統合 — MCPサーバーと組み合わせたスキルバンドル形式のプラグイン
