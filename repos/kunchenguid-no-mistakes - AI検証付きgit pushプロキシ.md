# kunchenguid/no-mistakes

▎ AI検証付きgit pushプロキシ

ライセンス: MIT
言語: Go

---
## 概要

git pushコマンドをインターセプトし、AIエージェントによる自動検証パイプラインを実行してからリモートリポジトリにプッシュするローカルgitプロキシツール。`git push no-mistakes`と入力するだけで、使い捨てのgit worktreeを生成し、AIエージェント（Claude、Codexなど）が自動的にコード検証を行い、安全な修正は自動適用、判断が必要な問題は人間にエスカレーションする。すべてのチェックがパスした後にのみ設定されたプッシュ先にブランチを転送し、PRを自動作成する。メインの開発フローを中断することなくバックグラウンドで動作するため、開発者の生産性を損なわない。Go言語で実装されており、TUIコマンドやエージェントスキルとしても起動可能。

---
## 主な機能・特徴

- ノンブロッキング実行 — 開発フローを中断せずバックグラウンド検証
- マルチエージェント対応 — Claude、Codex等の複数AIで検証可能
- 自動安全修正 — 明確な問題は自動修正、曖昧な問題は人間判断
- 使い捨てWorktree — 隔離環境でのコード検証で本番コードを保護
- 自動PR作成 — チェック通過後にリモートプッシュとPR作成を自動化
- 3つのトリガー方式 — git push・TUIコマンド・エージェントスキル
- E2Eテスト — 複数AIエージェントでのエンドツーエンドテスト完備
